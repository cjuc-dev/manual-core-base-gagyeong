# ⚙️ Core 폴더 안내 (Server Logic)

본 폴더는 Smart Operations Suite(SOS)의 작동을 보장하는 핵심 서버 엔진 파일들을 포함하고 있습니다.

---

### 📂 주요 파일 구성

1.  **[server_engine.js](server_engine.js)**:
    *   **역할**: Node.js 기반의 All-in-One 서버 엔진입니다.
    *   **주요 기능**:
        - 웹 서비스 호스팅 (Port: 3000)
        - 청주도시공사 홈페이지 공지사항 자동 수집 (Scraper)
        - 정적 파일(HTML, CSS, JS) 라우팅
    *   **주의사항**: 공지사항 크롤링 대상 웹사이트의 구조가 변경될 경우 이 파일 내의 셀렉터 로직을 수정해야 합니다.

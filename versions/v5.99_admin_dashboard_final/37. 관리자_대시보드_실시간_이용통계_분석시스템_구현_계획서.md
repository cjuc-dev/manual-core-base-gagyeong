# 📋 37. 관리자 대시보드 실시간 이용통계 분석시스템 구현 계획서

## 1. 개요 및 목적
본 계획서는 청주도시공사 Smart Operations Suite (SOS) 통합 매뉴얼의 관리 가치를 극대화하기 위해, 실시간 사용자 활동 통계(조회수, 공감수, 검색어 빈도)를 안전하게 수집 및 적재하고 이를 관리자 전용 대시보드에 고품격 글래스모피즘 랭킹 카드로 시각화하는 지능형 통계 분석 시스템을 구현하는 것을 목적으로 합니다.

## 2. 보안 및 웹 접근성 설계 (지침 1 준수)
*   **디바운싱(Debouncing) 트래픽 통제**: 사용자가 검색어를 입력하는 실시간 도중에 무수한 API 요청이 유출되는 것을 차단하기 위해 500ms 지연 타이머를 탑재하여 최종 확정된 단어만 안전하게 전송합니다.
*   **중복 어택 및 새로고침 방어**: F5 새로고침 또는 불필요한 연속 탭 진입 시 조회수가 비정상 누적되는 것을 막기 위해 `localStorage` 기반 당일 조회 세션 검증 필터를 이식합니다.
*   **시큐어 코딩 및 마스킹**: 통계 노출 시 개인정보 유출 방지 및 물리 파일명 마스킹을 엄격하게 적용하여 보안 취약점을 차단합니다.

## 3. 상세 구현 설계
*   **집계 컬렉션 추가**:
    *   `manual/system_info/analytics_views/{contentId}`: 누적 조회수 (에메랄드 프로그레스 바)
    *   `manual/system_info/analytics_likes/{contentId}`: 누적 공감수 (로즈 핑크 그라데이션 하트)
    *   `manual/system_info/analytics_keywords/{keyword}`: 실시간 검색어 랭킹 (메달 배지 및 변동 화살표)
*   **코어 스크립트 수정**:
    *   `core/markdown_parser.js`: 마크다운 로딩 성공 콜백 시 중복 검증 후 조회수 `+1` 증분
    *   `core/likes_manager.js`: 로컬 좋아요 클릭 및 토글 해제 감지 시 `+1` / `-1` 연동 동기화
    *   `core/search_engine.js`: 500ms 디바운스 완료 시 최종 검색 단어 Firestore 누적 전송
*   **관리자 랭킹 시각화**:
    *   `pages/helpdesk/db_manager.html`에 "이용통계 분석" 프리미엄 분석 탭을 레이아웃 빌드하여 실시간 TOP 10 3대 랭킹 보드를 완성합니다.

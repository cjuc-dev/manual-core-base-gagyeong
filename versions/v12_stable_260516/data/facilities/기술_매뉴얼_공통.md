# 💻 기술 (Tech) 매뉴얼

체육시설 내 전산장비 및 예약 시스템의 유지보수 기술 지침입니다.

## 1. 예약 시스템 장애 발생 시 대응
1. **서버 접속 확인**: 관리자 모드로 접속하여 메인 DB(Firebase 등) 통신 상태를 체크합니다.
2. **트래픽 분산**: 수강신청 기간 등 접속 폭주 시, 대기열 시스템의 임계값을 조정합니다.
3. **MFA 인증**: 시스템 장애 복구를 위해 원격 접속 시 반드시 다중 인증(MFA)을 거쳐야 합니다.

## 2. 네트워크 장비 점검표
* 주 1회 (매주 월요일) 전산실 라우터 및 스위치 재부팅
* 무선 AP(Wi-Fi) 연결 상태 모니터링
* 키오스크 네트워크 핑(Ping) 테스트

# 📑 20. 지능형 검색 인덱스 시스템 구축 계획서

본 문서는 현재의 실시간 파일 탐색 방식 검색 엔진을 '사전 빌드된 인덱스(Pre-built Index)' 기반의 지능형 시스템으로 업그레이드하기 위한 계획을 수립합니다.

## 1. 개요
현재의 검색 시스템은 검색 시마다 모든 파일을 개별적으로 읽어 성능 저하의 잠재적 리스크가 있습니다. 이를 해결하기 위해 하나의 통합된 JSON 인덱스 파일을 활용하여 속도와 정확도를 극대화합니다.

## 2. 주요 개선 사항

### 2.1 검색 성능 및 정확도
*   **통합 인덱스 (`search_index.json`)**: 모든 매뉴얼 본문과 메타데이터를 하나의 파일로 통합 관리.
*   **제목 가중치 적용**: 검색어가 제목에 포함된 문서를 우선순위로 정렬.
*   **문맥 스니펫 (Context Snippet)**: 검색 결과 리스트에서 검색어가 포함된 문장을 더 지능적으로 추출하여 표시.

### 2.2 보안 및 유지관리 (지침 준수)
*   **XSS 원천 차단**: 인덱싱 단계에서 모든 HTML 태그를 제거한 순수 텍스트만 저장.
*   **자동화**: 신규 매뉴얼 파일 추가 시 인덱스를 자동으로 갱신할 수 있는 스크립트 기반 마련.

## 3. 상세 구현 계획

### 3.1 인덱스 생성 로직 (`buildSearchIndex`)
*   `data/` 폴더 내 모든 `.md` 파일을 자동으로 스캔.
*   마크다운 문법 특수문자 제거 및 텍스트 정규화.
*   `search_index.json`으로 결과 저장.

### 3.2 프론트엔드 연동 (`index.html`)
*   페이지 로드 시 개별 파일 fetch 대신 `search_index.json` 단일 호출.
*   검색 엔진 로직을 인덱스 기반 필터링 및 가중치 정렬 방식으로 변경.

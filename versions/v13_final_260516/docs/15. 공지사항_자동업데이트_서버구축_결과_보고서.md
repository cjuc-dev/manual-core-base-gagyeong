## 1. 구현 성과 요약
기존의 수동 크롤링(Python) 및 단순 HTML 열기 방식을 벗어나, **Node.js 기반의 가벼운 웹 서버**와 **백그라운드 자동 크롤러**를 성공적으로 결합했습니다. 
이제 서버를 켜두기만 하면, 사용자가 전혀 신경 쓰지 않아도 **1시간마다 알아서 최신 공지사항을 긁어와 화면을 갱신**합니다.

## 2. 핵심 개발 내역

### 1️⃣ Node.js 전용 무설치 크롤러 (`scripts/auto_crawler.js`)
*   과거 Python 실행 시 윈도우 스토어가 열리던 환경 문제를 근본적으로 해결하기 위해, 사용자님 환경(Node.js)에 완벽하게 호환되는 **자바스크립트(JS) 크롤러**를 새로 개발했습니다.
*   외부 라이브러리(`axios`, `cheerio` 등)를 전혀 쓰지 않고 오직 Node.js 기본 내장 모듈(`https`)만 사용하여, **복잡한 설치 과정(`npm install`) 없이 더블클릭만으로 즉시 작동**하도록 만들었습니다.

### 2️⃣ 초경량 통합 서버 (`server.js`)
*   마찬가지로 `Express` 같은 외부 프레임워크 없이 순수 Node.js만으로 구동되는 **초경량 통합 서버**를 구축했습니다.
*   **투트랙 작동 방식**:
    1.  사용자가 `http://localhost:3000`으로 접속하면 `index.html` 대시보드 화면을 띄워줍니다.
    2.  동시에 서버의 뒷단(Background)에서는 방금 만든 `auto_crawler.js`를 **1시간 주기로 몰래(?) 실행**하여 `notices.json` 데이터를 조용히 갱신합니다. (대상 웹사이트 서버 부하 완벽 방지)

### 3️⃣ 사용자 편의 스크립트 (`start.bat`)
*   명령어(CMD) 창을 무서워하거나 귀찮아하는 일반 관리자도 **아이콘 더블클릭 한 번**으로 서버 구동과 스케줄러를 동시에 켤 수 있도록 윈도우용 배치 파일(`start.bat`)을 만들었습니다.

## 3. 새로운 접속 및 실행 방법 (Next Step)
이제부터 이 시스템을 이용하실 때는 다음 순서를 따르시면 됩니다!

1.  폴더 안에 새로 생긴 **`start.bat`** 파일을 더블클릭합니다. (검은색 창이 뜨면서 서버가 켜집니다.)
2.  인터넷 브라우저 주소창에 **`http://localhost:3000`** 이라고 치고 들어갑니다.
3.  **끝입니다!** 창을 닫지 않는 이상 1시간마다 최신 글로 자동 업데이트됩니다.

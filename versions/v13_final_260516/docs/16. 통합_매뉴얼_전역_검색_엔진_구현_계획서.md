# 📑 16. 통합 매뉴얼 전역 검색 엔진 구현 계획서

본 문서는 SOS 시스템 내의 모든 문서(Markdown) 내용을 실시간으로 탐색할 수 있는 '전역 검색 엔진' 구축 계획을 수립합니다.

## 1. 개요
현재 키워드 매핑 방식의 검색은 새로운 문서가 추가될 때마다 수동으로 키워드를 업데이트해야 하는 한계가 있습니다. 이를 해결하기 위해 모든 `.md` 파일의 내용을 직접 파싱하여 검색하는 동적 검색 시스템을 도입합니다.

## 2. 주요 설계 방향 (시큐어 코딩 지침 준수)

### 2.1 보안 및 안정성
*   **XSS 방지**: 검색 결과 출력 시 `DOMPurify`를 사용하여 스크립트 삽입 공격을 원천 차단합니다.
*   **파일 접근 제어**: 지정된 `data/` 폴더 내의 파일만 읽도록 경로를 제한합니다.

### 2.2 UI/UX 개선
*   **실시간 결과**: 입력 즉시 결과가 나타나는 'Incremental Search' 구현.
*   **미리보기**: 매칭된 단어가 포함된 문장의 앞뒤 맥락을 함께 보여주어 검색 효율성을 높입니다.

## 3. 상세 구현 계획

### 3.1 검색 인덱서 (JavaScript)
*   프로젝트 내 모든 `.md` 파일 목록을 사전에 정의하거나, 서버가 시작될 때 파일 내용을 읽어 메모리에 캐싱합니다.
*   사용자 입력 쿼리를 정규표현식으로 변환하여 파일 내용과 대조합니다.

### 3.2 프론트엔드 연동 (`index.html`)
*   `performSearch` 함수를 개선하여 단순 키워드 매칭이 아닌 파일 내용 전문(Full-text) 검색으로 전환합니다.
*   결과 클릭 시 해당 문서의 특정 위치로 스크롤하거나 강조하는 기능을 검토합니다.

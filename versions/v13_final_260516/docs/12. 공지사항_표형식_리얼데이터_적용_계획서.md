# [공지사항 게시판: 오리지널 표(Table) 형식 및 실데이터 동기화 계획서]

사용자님의 예리한 지적에 감사드립니다. 현재 나타난 데이터는 UI 시연을 위해 제가 임의로 만든 **'가짜 더미 데이터(Dummy Data)'**였습니다. (이전 작업 시 사용자님 PC의 Python 환경 설정 문제로 로봇이 직접 실행되지 못해 임시 데이터를 넣었습니다.)

올려주신 두 번째 스크린샷(원본 게시판)과 완벽히 동일한 형태의 **표(Table) 형식 UI**로 변경하고, **실제 데이터**를 가져오는 작업을 제안합니다.

## Proposed Changes

### 1. UI 구조 전면 개편 (리스트형 → 오리지널 표 형식)
- **[MODIFY] `index.html`**:
  - 기존의 줄무늬 리스트(`<ul>`, `<li>`) 방식을 폐기하고, 스크린샷과 똑같은 **`<table>` 태그 방식**으로 레이아웃을 전면 개편합니다.
  - 표의 헤더 컬럼: `[제목]`, `[작성자]`, `[등록일]`, `[조회]`
  - '공지' 딱지가 붙은 상단 고정 게시물에는 빨간색 **[N]** 아이콘이나 굵은 글씨 효과를 추가하여 원본의 느낌을 100% 살립니다.

### 2. 크롤러 데이터 항목 추가 (`scripts/fetch_notices.py`)
- **[MODIFY]**: 파이썬 크롤링 로봇이 단순히 제목과 내용만 가져오던 것에서, **'작성자(체육사업부 등)'**와 **'조회수(Hit)'**까지 수집하도록 정규식(Regex)을 정교하게 다듬습니다.

### 3. 실제 데이터 동기화
- 제가 임의로 만든 가짜 데이터(`notices.json`)를 지우고, 원본 사이트(https://www.cjuc.or.kr/home/sub?menukey=7401)에 현재 올라와 있는 **진짜 데이터 50개(약 5페이지 분량)**를 긁어와서 삽입합니다.

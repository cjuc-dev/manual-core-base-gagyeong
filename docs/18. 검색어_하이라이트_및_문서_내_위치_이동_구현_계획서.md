# 📑 18. 검색어 하이라이트 및 문서 내 위치 이동 구현 계획서

본 문서는 검색 결과 클릭 시 해당 키워드를 문서 내에서 강조(형광펜 효과)하고, 사용자의 시선을 즉시 해당 위치로 이동시키는 UX 고도화 계획을 수립합니다.

## 1. 개요
전역 검색 엔진 도입으로 방대한 데이터를 찾기는 쉬워졌으나, 클릭 시 문서 상단으로만 이동하여 사용자가 다시 검색어를 찾아야 하는 번거로움이 있습니다. 이를 해결하기 위해 '자동 스크롤' 및 '하이라이트' 기능을 도입합니다.

## 2. 주요 설계 방향 (지침 준수)

### 2.1 시큐어 코딩 및 보안
*   **XSS 방지**: 하이라이트 처리 시 `innerHTML`을 사용하되, 검색어 이외의 원본 텍스트는 반드시 `DOMPurify`로 정제한 후 강조 태그(`<mark>`)를 삽입합니다.
*   **안정성**: 존재하지 않는 키워드나 특수문자 검색 시 에러가 발생하지 않도록 예외 처리를 강화합니다.

### 2.2 UX 개선 (형광펜 효과)
*   **시각적 강조**: `<mark>` 태그 또는 배경색 클래스를 사용하여 형광펜 효과를 부여합니다.
*   **자동 위치 이동**: `scrollIntoView` API를 사용하여 하이라이트된 첫 번째 요소로 화면을 부드럽게 이동시킵니다.

## 3. 상세 구현 계획

### 3.1 검색어 전달 로직 개선
*   `loadContent` 함수 호출 시 검색어(`query`)를 파라미터로 함께 전달합니다.
*   문서 렌더링 완료 후 검색어와 매칭되는 텍스트 노드를 찾아 강조용 HTML로 치환합니다.

### 3.2 하이라이트 및 스크롤 함수 구현
*   `highlightText(container, query)`: 지정된 컨테이너 내에서 텍스트를 탐색하여 강조 표시.
*   최초 매칭 지점으로 `smooth scroll` 처리.

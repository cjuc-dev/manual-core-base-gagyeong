# [Phase 9: 공지사항 자동 업데이트(스케줄링) 서버 구축 계획서]

사용자님의 요청에 따라, 공지사항을 수동으로 업데이트하는 방식에서 **알아서 최신화되는 자동 업데이트 시스템**으로 고도화하는 작업을 제안합니다.

## Proposed Changes

현재 환경은 더블클릭으로 HTML을 여는 오프라인(정적) 상태이므로, 백그라운드에서 주기적으로 로봇을 돌려줄 심장(서버)이 필요합니다. 사용자님의 선호 스택인 **Node.js**를 활용하여 매우 가볍고 안정적인 자동화 서버를 구축하겠습니다.

### 1. 자동화 전용 로봇 개발 (`scripts/auto_crawler.js`)
- **[NEW] `scripts/auto_crawler.js`**: 
  - 기존 파이썬 로봇 대신, Node.js 기반의 크롤링 로봇을 작성합니다. (이전 파이썬 실행 시 Windows 스토어가 열리는 등의 환경 오류를 원천 차단하기 위함)
  - 이 로봇은 `https://www.cjuc.or.kr`의 데이터를 파싱하여 `data/notices.json`을 덮어씁니다.

### 2. 백그라운드 스케줄링 서버 구축 (`server.js`)
- **[NEW] `server.js`**:
  - 프로젝트 최상단에 Node.js 서버 파일을 생성합니다.
  - **기능 1 (정적 파일 제공)**: `index.html` 등 대시보드 화면을 띄워줍니다. (`http://localhost:3000` 접속)
  - **기능 2 (자동 스케줄링)**: 서버가 켜져 있는 동안 **1시간 단위(3600000ms)**로 `auto_crawler.js`를 백그라운드에서 조용히 실행시킵니다.
  - 상대측 서버(청주도시공사)에 무리가 가지 않도록, 사용자가 아무리 새로고침을 많이 해도 크롤링은 **오직 1시간에 1번만** 수행되도록 안전하게(부하 방지) 설계합니다.

### 3. 시작 스크립트 작성 (`start.bat`)
- **[NEW] `start.bat`**: 
  - 초보자도 더블클릭 한 번으로 서버와 자동 업데이트 봇을 동시에 켤 수 있도록 윈도우용 실행 파일을 제공합니다.

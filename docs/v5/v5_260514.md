# 🚀 Release Note - v5.0.0 (2026-05-14)

본 문서는 전역 검색 엔진 도입 및 가경국민체육센터 매뉴얼 고도화에 따른 릴리스 내역을 기록합니다. (v5 버전 유지)

## ⚠️ 작업 프로세스 중요 지침 (Operational Rule)
*   **자율 진행 금지**: 모든 작업 완료 후 '다음 단계'로의 전환은 반드시 사용자의 **진행 요청** 또는 **명령**이 있을 때만 수행합니다.
*   **승인 대기**: AI는 작업 결과를 보고하고 다음 단계를 제안할 수 있으나, 사용자의 승인 없이 임의로 신규 파일 생성이나 코드 수정을 시작하지 않습니다.
*   **기록 의무**: 매 단계 완료 시마다 릴리스 노트를 즉시 업데이트하여 변경 이력을 투명하게 관리합니다.

## 1. 주요 변경 사항

### 🔍 전역 검색 시스템 (Full-text Search Engine)
*   **기능**: 이제 단순 제목 검색이 아닌, 매뉴얼 문서 **내부의 모든 텍스트**를 검색할 수 있습니다.
*   **대상**: `data/` 폴더 내의 모든 `.md` 파일.
*   **효과**: '클리닝 타임', '셔틀버스', '주차' 등 세부 키워드 검색 시 관련 문서를 즉시 찾아줍니다.

### 🏛️ 가경국민체육센터 매뉴얼 고도화 (완료)
*   **파일**: `data/gagyeong_sportscenter_guide.md` 신규 생성 및 UI 최종 확정.
*   **개선**: 기존 HTML의 모든 데이터(시설 개수, 요금, 운영시간 등)를 누락 없이 마크다운으로 변환.
*   **시각화**: 가로 3장씩(2*3 그리드) 배치 및 실선 없는 심플한 프리미엄 UI 적용 완료.
*   **UX**: 탭 UI 및 가시성이 높은 표 형식을 적용하여 가독성 극대화.

### 🏊 청주수영장 매뉴얼 고도화 (완료)
*   **파일**: `data/cheongjuSwimming_guide.md` 생성.
*   **데이터 준수**: `cheongju_swimming_pool_guide_v1.html`의 데이터를 원본 그대로 엄격히 이식 (운영시간, 휴장일, 강습표, 요금 체계 등).
*   **시각화**: 가경센터 md를 베이스로 한 **2*3 그리드** 및 **실선 제거 심플 UI** 적용.
*   **시스템**: 통합 검색 인덱스 갱신을 통해 원본 데이터 기반 키워드 검색 지원.
### 📐 전 시설 매뉴얼 표준화 및 UI 최적화 (가경 모델 확산)
*   **표준화 완료**: 푸르미, 영운, 복대, 청주수영장 매뉴얼을 가경센터의 표준 레이아웃(3x2 그리드, 표 병합 등)으로 일괄 개편.
*   **갤러리 규격 통일**: 모든 시설의 이미지를 **4:3 황금 비율(aspect-ratio: 4/3)**로 고정하여 시각적 통일성 확보.
*   **데이터 무결성**: 각 시설별 원본(1.html)의 실제 수량, 요금, 운영 시간을 정밀 이식.

### 🛡️ 사이버보안 관리자 대시보드 및 지능형 검색 보강
*   **보안 관제 센터**: 관리자 전용 대시보드(pages/admin_dashboard.html) 신규 구축.
*   **엔진 수동 제어**: 검색 인덱스 갱신 및 공지사항 크롤러를 대시보드에서 직접 실행 가능.
*   **검색 키워드 보강**: '주차', '샤워', '락커', '할인', '환불' 등 핵심 키워드를 전 시설 매뉴얼에 보강하여 검색 품질 극대화.
*   **MFA 인증 준비**: Google Authenticator 기반의 다중 인증(MFA) 도입 계획 수립 (22번 문서).

### 🏢 차기 작업 안내 (Next Steps)
*   **대상**: 푸르미스포츠센터 매뉴얼 고도화 (`data/purmi_guide.md`)
*   **내용**: 복합 체육 시설 특성에 맞춘 이미지 갤러리 및 운영 안내 마크다운화 진행 예정.

### 🔍 지능형 검색 및 UX 고도화 (Smart Search & Highlight)
*   **엔진 전환**: 실시간 파일 탐색 방식에서 사전 빌드된 **지능형 인덱스(Pre-built Index)** 방식으로 전환하여 검색 속도 및 정확도 극대화.
*   **가중치 정렬**: 제목(Weight: 50)과 본문 매칭을 점수화하여 최적의 결과를 상단에 우선 배치.
*   **문맥 스니펫**: 검색 결과 목록에서 키워드가 포함된 문장을 **굵게(Bold)** 표시하여 가시성 확보.
*   **마스킹 & 스크롤**: 검색 결과 클릭 시 해당 위치로 **자동 스크롤** 및 **형광펜(Yellow Highlight) 시각적 피드백** 기능 구현.

## 2. 보안 및 지침 준수 사항 (Secure Coding)
*   **입력 무결성**: 모든 검색 결과 출력물에 `DOMPurify` 100% 적용하여 XSS 보안 강화.
*   **지능형 노드 탐색**: HTML 태그를 보호하며 텍스트만 안전하게 마스킹하는 `walkNodes` 알고리즘 적용.
*   **문서 관리**: `docs/` 폴더 내 순차 번호(`16.` ~ `21.`)를 부여한 계획서 및 보고서 물리 파일 생성 완료.

## 3. 향후 계획
*   타 시설(청주수영장, 복대센터 등)의 매뉴얼도 가경센터와 동일한 고퀄리티 마크다운으로 순차적 변환 예정.
*   문서량이 수백 개로 늘어날 경우를 대비한 검색 인덱스 자동 갱신 툴 유지관리.

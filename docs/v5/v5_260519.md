## 1. 세부 구조 변경 및 구현 내역

### A. MutationObserver 기반의 iframe 동적 높이 팽창형 리사이저 탑재
*   **문제 원인**: `index.html` 내에서 관제실을 불러올 때, `markdown_parser.js` 파일의 iframe 컨테이너가 `h-[800px]` 고정 높이를 취하고 있었습니다. iframe 내부 페이지의 scrollHeight가 이 높이를 초과하면서 iframe 자체에 독립 스크롤바가 생기고, 부모의 `#mainScrollArea` 스크롤바와 중첩되어 **극악의 이중 스크롤바 결함**이 발생했습니다.
*   **해결책 (`resizeAdminIframe` 엔진 설계)**:
    ```javascript
    window.resizeAdminIframe = function(iframe) {
        if (!iframe) return;
        try {
            const setHeight = () => {
                const innerDoc = iframe.contentDocument || iframe.contentWindow.document;
                if (innerDoc && innerDoc.body) {
                    const newHeight = Math.max(
                        innerDoc.body.scrollHeight, 
                        innerDoc.documentElement.scrollHeight,
                        innerDoc.body.offsetHeight,
                        innerDoc.documentElement.offsetHeight
                    );
                    iframe.style.height = (newHeight + 40) + 'px';
                }
            };
            setHeight();
            iframe.addEventListener('load', setHeight);
            
            const innerWindow = iframe.contentWindow;
            const innerDoc = iframe.contentDocument || innerWindow.document;
            if (innerDoc && innerDoc.body && innerWindow.MutationObserver) {
                const observer = new innerWindow.MutationObserver(() => {
                    setHeight();
                });
                observer.observe(innerDoc.body, { attributes: true, childList: true, subtree: true });
                innerWindow.addEventListener('unload', () => observer.disconnect(), { once: true });
            }
        } catch (e) {
            console.warn("[SOS Resizer] 크로스 도메인 보안 제약 또는 오버라이드 통과:", e);
        }
    };
    ```
    iframe이 마운트되는 순간 내부의 실시간 DOM 변화(`MutationObserver`)와 리사이징 핸들러가 가동되어, iframe의 고유 높이를 내용물의 전체 실제 높이만큼 완전히 팽창시켜 줍니다. 이에 따라 iframe 내부의 독립 스크롤바는 **100% 영구 소멸**하고, 부모 브라우저 스크롤 하나에 네이티브하게 합류하여 완벽한 통합 포털의 일관된 휠링 사용감을 보장합니다.

### B. 관제실 제어 단추 개행 차단 및 좌측 설명 텍스트 쪼그라듬 결함 전면 해소
*   **Whitespace & Width 제어**: 관제실(`admin_dashboard.html`)의 제어 단추들에 `w-[135px]` 고정 너비 규격을 정형화하여 가지런하게 단추 크기를 1열 정돈했습니다.
*   **가독성 쪼그라듬 박멸**: 기존에 창 축소 시 우측 단추 영역이 좌측 설명 텍스트 영역을 과도하게 밀어내어 "인기 검색어 3" 다음 줄에 "대 보드를 분석합니다." 등으로 단어가 뚝뚝 끊기며 강제 줄바꿈이 일어나던 비주얼 결함을 완치하기 위해, 좌측 설명 `div` 영역에 `flex-1`, `pr-6`, `break-keep` 속성을 주입하여 한글 단어 단위 개행 및 충분한 가로 영역 넓이를 선제 보장했습니다.

### C. 대시보드 3대 인기 카드 이중 스크롤 박멸
*   **자연스러운 레이아웃 팽창**: `viewsRankContainer`, `likesRankContainer`, `keywordsRankContainer`에 기존 인가되어 있던 `max-h-[460px] overflow-y-auto` 제약 속성을 완전히 소거했습니다. 스크롤바 중첩으로 인해 생기던 화면 휠 버벅임 현상을 완치하고 극상에 다다른 브라우저 휠 사용성을 획득했습니다.

### D. 호버/클릭 동시 방어형 정보 안내 툴팁(Tooltip) 탑재
*   **다이내믹 가이드라인 제공**: 관제실 상단 3대 통계 카드의 좌측 아이콘 영역에 마우스 호버 시 또는 모바일 기기에서의 터치/클릭 시 반응형으로 스르륵 나타나는 반투명 글래스 툴팁 레이어를 구축했습니다.
*   **안전 오버랩 및 자동 클리어**: 툴팁 바디의 불필요한 번짐을 방지하고 `z-50 pointer-events-none`을 통해 텍스트 레이아웃을 해치지 않으며, 3.5초가 지나면 자동으로 스르륵 페이드 아웃되는 자동 소거 타이머 및 빈 바탕 클릭 시 전면 클리어 리스너를 결합해 초정밀 웹 경험을 보장합니다.

### E. 접속자 통계 4단계(오늘/주간/월간/누적) 마이크로 필터 스위칭 구현
*   **기간별 접속 현황 100% 가시화**: 단일 수치로 갇혀있던 "오늘 접속자 수" 카드를 확장하여, 오늘/주간/월간/누적 접속 통계를 유기적으로 검토할 수 있는 마이크로 스위칭 탭 필터를 이식했습니다.
*   **부드러운 카운트 렌더러**: 0.15초의 은은한 페이드 트랜지션 애니메이션을 자바스크립트로 연출하여 전환 시 통계 수치가 고급스럽게 바뀌도록 설계했습니다.

### F. 보안 감사 (Audit) 로그 개별 상세 설명 툴팁 완벽 탑재
*   **보안 명세의 투명성 확보**: 사이버보안 관제실 우측 실시간 감사 로그의 세부 아이콘들에 각각 마우스 호버 및 모바일 터치를 지원하는 상세 가이드 툴팁`[id=auditTooltip]`을 추가 탑재하여 보안 통제 규정을 즉각 해독할 수 있도록 구성했습니다.

### G. 실운영 가동을 위한 "실운영 통계 데이터 초기화" 보안 제어 엔진 탑재
*   **테스트 적재 통계 Zero 청소**: 개발 및 구축 중에 쌓인 접속 수치와 전역 검색 건수를 즉시 `0`으로 세팅하는 "실운영 통계 데이터 초기화" 제어 카드를 신설하고, 이중 승인 confirm 브릿지를 통한 `runResetStats` 자바스크립트 엔진을 탑재했습니다.
*   **실시간 감사 동적 피드백**: 초기화 실행 시 로컬 통계 데이터 캐시 삭제와 함께, 보안 감사 로그 최상단에 `[보안체계 준수] 실운영 통계 데이터 초기화 완료` 기록이 붉은색 펄스 애니메이션 배지와 함께 동적 마운트되어 관리자에게 시각적 확실성을 선사합니다.

### H. 공감 용어 -> 좋아요로의 전원 한글 표준 개편 (`core/likes_manager.js`)
*   **표준 명칭 교체**: 기존의 "공감" 용어는 공공기관 대민 서비스 상 사용성 및 직관성이 부족하다고 판단하여 대중적인 "좋아요" 명칭으로 100% 한글 용어 표준 개편을 완료했습니다.
*   **메시지 정교화**: 좋아요 토글 시 피드백 토스트 메시지 및 마크업 헤더와 단추 텍스트를 "좋아요"로 통일하여 사용성의 직관성을 극대화했습니다.

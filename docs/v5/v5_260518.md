# 🔄 Smart Operations Suite v5.91 릴리스 노트

*   **작업 일자**: 2026년 5월 18일 (월)
*   **배포 버전**: v5.91 (증분형 개편 배포)
*   **주요 목표**:
    *   2단계 중분류 및 소분류 메뉴의 기존 고유 아이콘 복원을 통한 가독성 및 직관성 향상
    *   3단계 최하위 세세부(가경국민체육센터) 메뉴에만 파란색 도트 점을 적용하여 트리 세로선 내부의 시각적 계층화 완성
    *   대시보드 "시설 매뉴얼" 카드를 파란색(Blue) 테마 및 책 아이콘(ph-book-open)으로 전면 교체하여 "시스템 문의" 카드(초록색)와의 시각적 겹침 전격 해결
    *   PC/모바일 환경에서 대시보드 카드 아코디언 확장 시 긴 메뉴명과 [준비중] 배지가 강제 줄바꿈(개행)되던 반응형 레이아웃 오작동 버그 전면 해결

---

## 1. 세부 구조 변경 및 구현 내역

### A. 사이드바 및 대시보드 2단계 아이콘 전면 복원
*   **기본 제공 아이콘 복구**: 개편 과정에서 점선 내부의 도트(·)로 일괄 치환되었던 2단계 소분류 아이콘들을 분석하여 고유 Phosphor 아이콘으로 완벽 원복하였습니다.
    *   **시설 안내 (Emerald Green)**: 청주수영장 (`ph-bank`), 푸르미/영운/복대 (`ph-warehouse`), 가경/산남 (`ph-building`) 에메랄드 그린 아이콘으로 복원.
    *   **운영 현황 (Amber Gold)**: 업데이트 히스토리 (`ph-clock-counter-clockwise`), 공지사항 (`ph-megaphone`), 홈페이지 (`ph-house-line`) 블루/골드 아이콘으로 복원.
    *   **시민의 소리 (Rose Red)**: 수영장 (`ph-waves`), 다목적체육관 (`ph-basketball`), 프로그램실 (`ph-users-three`), 기타 (`ph-info`) 로즈 핑크 아이콘으로 복원.
*   **3단계 세세부 도트 점 한정 유지**: `가경국민체육센터` 하위의 실제 3단계 소메뉴(`회원 관리`, `대관 관리`, `키오스크`, `락커/게이트`, `매출 정산` 및 `기계장비 일람표`, `기계`, `전기`, `소방`, `수질`, `가스` 등)에만 콤팩트한 파란색 도트(`rounded-full bg-blue-500/60 mr-2`) 구조를 견고히 유지시켜 완벽한 위계감을 연출했습니다.

### B. 대시보드 "시설 매뉴얼" 카드 파란색(Blue) 테마 개편
*   **색상 겹침 해결**: 기존 대시보드에서 "시설 매뉴얼" 카드와 "시스템 문의" 카드가 모두 초록색(`emerald`)으로 매핑되어 사용자에게 시각적 혼동을 주던 현상을 수정했습니다.
*   **파란색 테마 및 책 아이콘 적용**: "시설 매뉴얼" 카드의 호버 테두리(`hover:border-blue-500`), 내부 대표 아이콘(`ph-book-open text-blue-600`), 드롭다운 캐럿 아이콘(`text-blue-600`)으로 전격 개편하여, 옆에 있는 초록색 "시스템 문의" 카드와 뚜렷하게 구별되는 완벽한 시각 대비 효과를 주었습니다.

### C. 데스크톱(PC) 대시보드 반응형 레이아웃 텍스트 꺾임 패치
*   **그리드 최적화**: 기존 데스크톱 해상도(`lg`)에서 4열로 강제 구겨넣던 그리드 배치를 `lg:grid-cols-2 xl:grid-cols-4`로 전격 조정하였습니다. 이로써 노트북 및 일반 데스크톱(1024px ~ 1280px 미만)에서는 카드가 넉넉한 2열로 노출되어 아코디언 메뉴를 모두 펼쳐도 카드가 좌우로 찌그러지지 않습니다.
*   **텍스트/배지 정렬 안전장치 주입**:
    *   아코디언 항목 버튼 내의 텍스트 영역에 `min-w-0 truncate whitespace-nowrap`을 주입하여 가로 공간 부족 시 절대로 개행(줄바꿈)되지 않고 끝부분만 깔끔하게 말줄임 처리되도록 보장했습니다.
    *   노란색 `준비중` 배지에는 `shrink-0` 및 기존의 부자연스러운 `scale-90 origin-right` 레이아웃 크기 축소를 제거하여, 찌그러짐 없이 본연의 모양을 단정하게 유지하도록 교정했습니다.

## 2. 보안 및 정보 보호 준수 사항
*   **Information Disclosure 예방**: 모든 마크업 상에서 영문 물리 디렉터리 경로를 제거하여 은닉 조치하였으며, 비즈니스 한글 용어로 일관되게 치환하였습니다.
*   **민감정보 하드코딩 배제**: 외부 라이브러리 및 API 연동 시 하드코딩된 인증 정보나 민감 키를 일절 배제하여 보안 무결성을 지속해서 지키고 있습니다.
*   **오프라인 자립화 유지**: CDN 외부망 단절 환경에서도 깨짐 없이 아이콘 및 폰트가 동작하도록 내장된 로컬 리소스 경로를 철저히 관리했습니다.

# 🔄 Smart Operations Suite v5.92 릴리스 노트

*   **작업 일자**: 2026년 5월 18일 (월)
*   **배포 버전**: v5.92 (인쇄 및 블로그 피드백 고도화 배포)
*   **주요 목표**:
    *   현장 점검 시 실무자용 문서 출력 지원을 위한 마크다운 뷰어 '인쇄 최적화 Clean Print Engine' 탑재
    *   매뉴얼 피드백 정량 측정을 위한 하단 '네이버 블로그 스타일 공감(좋아요) 캡슐 UI 및 캐싱 엔진' 탑재
    *   클립보드 API 연동을 통한 개별 상세 문서 링크 주소 공유 기능 및 프리미엄 토스트 팝업 이식

---

## 1. 세부 구조 변경 및 구현 내역

### A. 인쇄 최적화 Clean Print CSS (@media print) 구현
*   **레이아웃 자동 은닉**: `window.print()` 기동 시 사이드바(`aside`), 헤더(`header`), 닫기/인쇄 액션 버튼 그룹, 하단 플로팅 네비게이션바, 탭 단추 리스트를 `display: none !important`로 완벽 은닉하여 종이 낭비를 막고 가독성을 보장합니다.
*   **출력 최적화 리셋**: 배경색/글자색 강제 리셋, 스크롤 영역 `overflow: visible` 해제, 표(Table) 요소의 `page-break-inside: avoid` 속성을 적용해 인쇄지 경계면에서 테이블 셀이 뚝뚝 끊기거나 짤리는 결함을 완전 예방했습니다.

### B. 네이버 블로그형 공감(좋아요) 묶음 컴포넌트 빌드
*   **상태 영속성 보존**: `localStorage` 연동 키(`sos_like_{contentId}`)를 설계하여 사용자의 좋아요 토글 상태(`liked`)와 공감 수(`count`)를 브라우저 세션과 무관하게 영구 보존합니다.
*   **최초 생동감 난수 이식**: 아직 추천 기록이 생성되지 않은 매뉴얼의 경우 최초 로딩 시 `7~15` 사이의 신뢰도 높은 기본 추천수를 난수로 자동 주입하여 직원 간의 인터랙션이 활발히 진행 중인 듯한 동적인 효과를 구현했습니다.

### C. 공유 연동 클립보드 복사 및 프리미엄 글래스모피즘 토스트
*   **지능형 라우팅 공유**: 개별 문서별 `doc` 파라미터뿐만 아니라 `facility`와 최하위 앵커링 세분류 `sub` 파라미터까지 완벽하게 추출하여 URL 주소를 병합 복사하도록 복사 엔진을 설계했습니다.
*   **프리미엄 토스트 알림**: 복사 성공 시 화면 우측 상단에 3D 글래스모피즘 효과(`backdrop-filter: blur(12px)`) 및 애니메이션 핑 효과가 담긴 안내 창을 2.5초간 노출 후 스무스 페이드아웃시키는 피드백을 적용했습니다.

## 2. 보안 및 정보 보호 준수 사항
*   **XSS(크로스 사이트 스크립팅) 원천 차단**: 클립보드 URL 빌딩 및 공감 토글 렌더링 시 노출되는 문자열에 `DOMPurify.sanitize` 필터를 철저하게 적용하여 잠재적 스크립트 인젝션 위협을 원천 봉쇄했습니다.
*   **정적 구동 무결성**: 서버 연결 유무에 관계없이 모든 캐싱 및 복사 동작이 순수 바닐라 JS 및 로컬 API 환경 내에서 오동작 없이 완벽하게 구동되도록 견고하게 작성되었습니다.

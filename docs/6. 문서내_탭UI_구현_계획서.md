# 시설별 매뉴얼 분리 및 조회 최적화 구현 계획

기존에는 '행정' 또는 '기술' 매뉴얼 클릭 시 단일 마크다운 파일만 불러왔으나, 시설별(청주수영장, 푸르미 등)로 규정이 상이하다는 점을 반영하여 **최적의 사용자 경험(UX)과 편의성**을 제공하는 방향으로 시스템을 개편합니다.

## 💡 최적의 방안 제안: [문서 내 다이내믹 탭(Tab) UI] 도입

대시보드에 시설 목록을 길게 나열하여 화면을 복잡하게 만드는 대신, **문서를 열었을 때 상단에 시설을 전환할 수 있는 '탭(Tab) 바'를 렌더링**하는 방식을 제안합니다.

### 이 방식의 장점 (편의성 및 UX 측면)
1. **비교 열람의 극대화**: 행정 매뉴얼을 보다가 '청주수영장'에서 '푸르미' 규정으로 넘어가고 싶을 때, 뒤로가기를 눌러 대시보드로 나갈 필요 없이 탭만 누르면 즉시 전환됩니다.
2. **대시보드 깔끔함 유지**: 6개 시설 × 2개 카테고리(행정/기술) = 12개의 버튼을 대시보드에 노출하지 않아도 되므로 직관성이 유지됩니다.
3. **URL 상태 저장 완벽 지원**: 브라우저 주소창 파라미터를 `?doc=행정_매뉴얼&facility=청주수영장` 형태로 기록하여, 뒤로가기나 링크 공유 시에도 해당 시설의 문서가 정확히 열립니다.

## 🛠️ 구현 상세 계획 (Proposed Changes)

### 1. 마크다운(`.md`) 파일 구조 재편성 (data/ 폴더)
기존 단일 파일을 시설별 파일로 분리 생성합니다.
*   `data/행정_매뉴얼_공통.md` (기본값)
*   `data/행정_매뉴얼_청주수영장.md`
*   `data/행정_매뉴얼_푸르미.md`
*   `data/기술_매뉴얼_공통.md`
*   `data/기술_매뉴얼_청주수영장.md` ... 등

### 2. index.html 로직(SPA 라우팅) 개편

#### [MODIFY] index.html
*   **Javascript `loadContent` 함수 수정**: 
    *   인자에 `facility` 파라미터 추가 (`loadContent(contentId, facility = 'common', isPopState = false)`)
    *   요청된 ID가 '행정_매뉴얼' 또는 '기술_매뉴얼'인 경우, `contentArea` 상단에 가로 스크롤이 가능한 모던한 디자인의 **시설 선택 탭 바(Tab Navigation)**를 동적 주입합니다.
    *   파일 Fetch 경로를 `data/${safeId}_${facility}.md` 형식으로 동적 할당합니다.
*   **브레드크럼(Breadcrumb) 동기화**: `홈 / 행정 (Admin) / 청주수영장` 형태로 현재 위치를 명확히 표시합니다.
*   **하이브리드 검색엔진 수정**: 특정 시설의 행정 매뉴얼 키워드 검색 시, 해당 탭으로 바로 이동할 수 있도록 메타데이터(`searchMetadata`) 구조를 업데이트합니다.

## 🚨 사용자 리뷰 필요 (User Review Required)

> [!IMPORTANT]
> **시설의 기본(Default) 탭 설정에 대한 결정**
> 사용자가 대시보드에서 처음 '행정' 버튼을 눌렀을 때, 1) **[공통]** 탭이 먼저 보이게 할지, 아니면 2) 가장 규모가 큰 **[청주수영장]** 탭이 기본으로 열리게 할지 결정해 주시면 맞춰서 구현하겠습니다. (제안: '공통' 가이드를 기본으로 보여주는 것이 가장 표준적입니다.)

## ✅ 검증 계획 (Verification Plan)
1. 대시보드에서 '행정 (Admin)' 클릭 시 탭 UI가 정상적으로 나타나는지 확인.
2. 탭 클릭 시 각 시설별 마크다운 파일이 페치(Fetch)되어 깜빡임 없이 렌더링되는지 테스트.
3. 브라우저 뒤로가기 클릭 시 탭 상태(Facility)까지 정확히 히스토리 복원되는지 검증.

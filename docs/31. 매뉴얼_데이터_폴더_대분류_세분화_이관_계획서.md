# 📑 [계획서] 매뉴얼 데이터 폴더 대분류(행정/기술) 세분화 및 라우팅 뼈대 선구축 계획서

*   **작성일자**: 2026. 05. 18.
*   **작성부서**: 청주도시공사 Smart Operations Suite (SOS) 개발단
*   **적용버전**: v5.50 (사이드바 대분류 '분야' 승격 개정 및 가경국민체육센터 행정/기술분야 마스터 인덱스 연동)

---

## 1. 개요 및 배경

### 1.1 개요
본 계획서는 기존의 복잡하고 방대한 매뉴얼 데이터 정비 작업을 슬림하게 쪼개어, **HTML ➔ 마크다운(`.md`) 전수 변환과 같은 대규모 작업을 추후 별도 단계적 계획으로 안전하게 연기**하고, 우선 선행되어야 할 **사이드바 메뉴 명칭 '분야' 개정, 상단 다단계 경로 네비게이션(Breadcrumb) 연동 및 가경국민체육센터의 분야별 마스터 인덱스(`.md`) 뼈대 구축**을 완수하기 위한 최적의 단기 이행 계획을 수립합니다.

> [!NOTE]
> **피드백 반영 범위 축소**
> 리스크가 큰 48개 HTML 개별 매뉴얼 파일들의 마크다운 전수 컨버팅은 본 계획에서 **완전히 제외**합니다. 이번 v5.50 릴리스에서는 오직 **구조 개편, 사이드바 명칭 개정, 상단 경로 연동 및 가경체육센터 마스터 인덱스(`.md`)의 안정적인 로딩**에만 집중하여 무결한 뼈대를 완벽 구축합니다.

### 1.2 주요 추진 목적
*   **직관적인 분류 체계 확립**: 기존의 단순 '매뉴얼' 표시를 **'행정 분야'** 및 **'기술 분야'**로 전격 정합하여 세련된 계층 메뉴를 구성합니다.
*   **경로 네비게이션 시각 정합성 확보**: 사이드바 메뉴 클릭 시 상단 Breadcrumb 경로가 **`홈 / 행정 분야 / 가경국민체육센터`** 및 **`홈 / 기술 분야 / 가경국민체육센터`** 로 깨짐 없이 표시되게 라우팅 엔진을 보완합니다.
*   **안정적인 인덱스 뼈대 선안착**: 가경국민체육센터의 이관된 행정/기술분야 마스터 인덱스 마크다운(`.md`) 파일을 비동기(`fetch`) 기법으로 안전하게 로드하고 렌더링되게 맵핑합니다.

---

## 2. 사이드바(Sidebar) & 경로 네비게이션 UI/UX 연동 설계

### 2.1 좌측 다단계 폴딩 사이드바 개정
사이드바의 "시설 매뉴얼" 하위 메뉴 명칭을 다음과 같이 직관적이고 세련되게 변경합니다.
*   **시설 매뉴얼 (대메뉴)**
    *   📝 **행정 분야 (중분류 - 명칭 변경)**
        *   클릭 시: `loadContent('admin_fields', '가경국민체육센터')` 호출
    *   🔧 **기술 분야 (중분류 - 명칭 변경 및 격상)**
        *   클릭 시: `loadContent('tech_fields', '가경국민체육센터')` 호출
    *   🛡️ **안전 표준매뉴얼 (중분류)**

### 2.2 상단 글로벌 경로 네비게이션(Breadcrumb) 연동
*   사용자가 '행정 분야'를 누르면 상단 서브헤더 경로가 **`홈 / 행정 분야 / 가경국민체육센터`** 로 시각적 오차 없이 빌딩됩니다.
*   사용자가 '기술 분야'를 누르면 상단 서브헤더 경로가 **`홈 / 기술 분야 / 가경국민체육센터`** 로 빌딩됩니다.

## 3. 라우터 경로 매핑 명세

`loadContent` 함수가 작동할 때 `facility` 값과 `safeId` 값을 조합하여 다음의 물리 마크다운 경로를 타겟팅하도록 `fetchPath` 로직을 동기화합니다.

1.  **행정 분야 (`admin_fields`)**
    *   시설명: `가경국민체육센터`
    *   로드 파일: `data/manual/admin/gagyeong/0. 가경국민체육센터_행정분야_인덱스.md`
2.  **기술 분야 (`tech_fields`)**
    *   시설명: `가경국민체육센터`
    *   로드 파일: `data/manual/tech/gagyeong/0. 가경국민체육센터_기술분야_인덱스.md`

## 4. 구 통합 매뉴얼 HTML ➔ 마크다운(`.md`) 변환 로드맵 (장기 연기)

> [!IMPORTANT]
> **향후 개별적 순차 변환 계획 수립 예정**
> 48개 조각 HTML 파일들의 정밀 마크다운 변환은 본 단계에서 폴더 세분화 뼈대 및 라우팅이 완전히 확보된 것을 확인한 뒤, 향후 별도의 마이그레이션 과제 및 개별 계획서(`33. 매뉴얼_본문_HTML_마크다운_컨버팅_계획서.md` 등)를 수립하여 순차 진행합니다. 본 차수에서는 오직 가경국민체육센터의 **행정분야 및 기술분야 인덱스 뼈대 파일 2개만 탑재**하여 연동을 검증합니다.

## 5. 검증 계획

### 5.1 시각 무결성 검증 시나리오
1.  **사이드바 렌더링 검증**: 사이드바의 "시설 매뉴얼" 클릭 시 "행정 분야" 및 "기술 분야"로 메뉴명이 올바르게 표시되는지 확인합니다.
2.  **가경체육센터 로드 검증**: 각 메뉴 클릭 시 `data/manual/` 내의 뼈대 인덱스 마크다운 문서가 에러 없이 로딩되는지 확인합니다.
3.  **상단 브레드크럼 매칭 검증**: 상단 네비게이션 바에 `홈 / 행정 분야 / 가경국민체육센터` 와 같이 사용자가 요청한 깊이까지의 경로가 시각적으로 오차 없이 렌더링되는지 최종 검증합니다.

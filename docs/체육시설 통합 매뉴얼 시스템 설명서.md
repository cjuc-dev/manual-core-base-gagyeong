## 🏗️ 시스템 아키텍처

시스템은 관리의 편의성과 보안성을 위해 **올인원 서버 엔진(All-in-One Server Engine)** 구조를 채택하고 있습니다.

```text
체육시설 통합 매뉴얼/
├── core/
│   └── server_engine.js      # 🚀 All-in-One 서버 (웹 서비스 + 공지 수집 통합)
├── data/
│   ├── facilities/           # 🏢 시설별 마크다운 매뉴얼 데이터 (.md)
│   └── system/               # ⚙️ 시스템 설정 및 공지 DB (.json)
├── scripts/                  # 🛠️ 개발 지원 및 자동화 도구
├── docs/                     # 📚 시스템 가이드 및 운영 기록
├── index.html                # 🌐 메인 대시보드 UI (Single Page App)
└── start.bat                 # ⚡ 원클릭 시스템 실행기
```

## ⚙️ 주요 기능

| 분류 | 기능 | 설명 |
|---|---|---|
| **서버 엔진** | **All-in-One Service** | 웹 서버 가동과 동시에 최신 공지사항을 자동 수집/갱신 |
| **UX/UI** | **스마트 네비게이션** | 스크롤 시 화면 하단에 나타나는 스티키 바 (홈·탑·닫기) |

| **문서 관리** | **계층형 데이터** | 시설별 매뉴얼과 시스템 설정을 분리하여 독립적 관리 가능 |
| **안정성** | **이중 백업 시스템** | Git 버전 관리와 물리적 snapshot(versions/) 동시 운영 |

## 🚀 운영 및 배포

- **로컬 실행:** `start.bat` 실행 시 Node.js 기반 서버 가동 (Port: 3000)
- **공지 수집:** 서버 가동 중 매시간 또는 재시작 시 자동으로 최신 공지사항 수집
- **환경 최적화:** `type | node` 방식의 파이프라인 실행으로 보안 환경 우회 및 가용성 확보

---

## 📋 시스템 관리 가이드

1. **매뉴얼 수정**: `data/facilities/` 폴더 내의 해당 `.md` 파일을 직접 수정 (저장 시 즉시 반영). 모든 매뉴얼은 이 폴더 내에서 통합 관리됩니다.
2. **공지사항 관리**: 서버 엔진이 `data/system/notices.json`을 자동으로 관리함.
3. **인덱스 갱신**: 파일 추가/삭제 시 `scripts/build_search_index.js`를 실행하여 검색 엔진 색인을 최신화하십시오.

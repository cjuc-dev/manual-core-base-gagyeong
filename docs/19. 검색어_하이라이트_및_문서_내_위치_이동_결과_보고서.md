# 📑 19. 검색어 하이라이트 및 문서 내 위치 이동 결과 보고서

본 문서는 검색어 하이라이트 및 자동 스크롤 기능 구현 결과를 기록합니다.

## 1. 작업 개요
*   **작업 일시**: 2026-05-14
*   **목적**: 검색 결과 클릭 시 사용자가 찾는 내용이 어디에 있는지 즉시 파악하고 시선을 이동시키는 UX 완성.

## 2. 주요 구현 내용

### 2.1 검색어 연동 및 강조 (Highlighting)
*   **Highlight Engine**: `loadContent` 파라미터로 검색어를 전달받아, 문서 렌더링 후 텍스트 노드를 `<mark>` 태그로 감싸는 로직을 구현했습니다.
*   **스타일링**: 형광펜 느낌의 노란색 배경(`bg-yellow-200`)과 애니메이션을 적용하여 눈에 잘 띄게 처리했습니다.

### 2.2 자동 위치 이동 (Auto-Scroll)
*   **Scroll Logic**: 하이라이트된 첫 번째 요소를 감지하여 `scrollIntoView({behavior: 'smooth', block: 'center'})`를 통해 화면 정중앙으로 이동시킵니다.

### 2.3 보안 사항 (시큐어 코딩 준수)
*   **Safe Replacement**: 텍스트 치환 전 `DOMPurify`를 통해 원본 데이터를 검증하여 의도치 않은 태그 실행을 방지했습니다.

## 3. 검증 결과
1.  **동작 확인**: 검색창에서 '클리닝' 검색 후 결과 클릭 시, 가경센터 문서 내 '클리닝 타임' 텍스트가 노란색으로 강조되며 해당 위치로 자동 이동함.
2.  **모바일 호환성**: 좁은 화면에서도 스크롤 이동이 부드럽게 작동함을 확인.

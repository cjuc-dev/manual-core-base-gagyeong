# [공지사항 크롤링 및 자동화 위젯 구현 계획서]

현재 외부 API가 없는 청주도시공사 홈페이지의 공지사항을 SOS 시스템으로 가져오기 위해, **웹 크롤링(Web Crawling)** 기법을 활용한 파이프라인을 구축합니다.

## User Review Required

> [!IMPORTANT]
> 본 기능은 사용자가 직접 코딩할 필요 없이 **AI가 100% 코드를 작성**해 드립니다.
> 크롤링 특성상 원본 사이트(청주도시공사 홈페이지)의 디자인이나 웹페이지 구조가 크게 개편될 경우 데이터 수집이 일시 중단될 수 있습니다. (이 경우 AI에게 다시 에러 로그만 주시면 5분 안에 구조를 업데이트할 수 있습니다.)

## 확정된 기획 방향 (사용자 피드백 반영)

> [!NOTE]
> 1. **실시간 모니터링 대체**: 대시보드의 실시간 모니터링 영역의 필요성이 낮으므로, 해당 메뉴를 **[공단 최신 공지사항]**으로 완전히 대체합니다.
> 2. **미래 확장 (Admin Page)**: 방문자 통계, 접속 기록 등 진정한 의미의 모니터링 기능은 향후 별도의 '관리자 페이지'를 기획할 때 구현하는 방향으로 확정되었습니다.

## Proposed Changes

### 1. 크롤러 스크립트 작성 (Python)

#### [NEW] [fetch_notices.py](file:///d:/Smart%20Operations%20Suite/%EC%B2%B4%EC%9C%A1%EC%8B%9C%EC%84%A4%20%ED%86%B5%ED%95%A9%20%EB%A7%A4%EB%89%B4%EC%96%BC/scripts/fetch_notices.py)
- 외부 의존성(라이브러리 설치) 없이 파이썬 기본 모듈(`urllib`, `html.parser`, `re`)만 사용하여 누구나 쉽게 실행할 수 있는 크롤링 로직 작성.
- `https://www.cjuc.or.kr/home/sub?menukey=7401` 에 접속하여 최신 공지사항 제목, 작성일, 링크 주소를 추출.
- 추출한 데이터를 `data/notices.json` 파일로 자동 저장.

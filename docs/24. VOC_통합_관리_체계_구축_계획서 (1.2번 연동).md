# 📋 VOC(시민의 소리) 통합 관리 체계 구축 계획서 (1.2번 연동)

본 문서는 `voc/` 폴더 내에 파편화되어 있는 HTML 기반의 VOC 데이터를 마크다운(.md)으로 통합하고, SPA 환경에 최적화된 동적 로딩 및 보안 강화(마스킹)를 구현하기 위한 계획서입니다.

## 1. 목적
*   **지침 준수**: [지침 2]에 의거, 레거시 HTML을 MD로 변환하여 `data/` 폴더로 이관하고 전역 검색에 연동함.
*   **보안 강화**: [지침 1]에 의거, 작성자 성함 등 개인정보를 출력 시 마스킹 처리(`홍*동`)함.
*   **관리 효율성**: 분산된 VOC 데이터를 하나의 통합 인덱스와 카테고리별 MD 파일로 관리하여 유지보수 편의성 증대.

## 2. 주요 변경 사항

### 2.1 UI/UX 구조 대칭화 (Sidebar & Main Dashboard)
*   **사이드바(Sidebar)**: '매뉴얼', '현황', 'VOC'를 각각 독립적인 아코디언 메뉴군으로 분리하여 접근성 강화.
*   **메인 대시보드(Main Dashboard)**: 초기 진입 화면(Main Scroll Area)에 '매뉴얼', '현황', 'VOC' 3개 핵심 모듈을 카드 형태로 배치하여 시각적 직관성 제공.

### 2.2 데이터 구조 개편 (Data Migration)
*   **기존**: `pages/voc/` 내의 여러 HTML 파일 및 `voc_data.js`
*   **변경**: `data/voc/` 폴더 신설 및 카테고리별 MD 파일 생성
    *   `data/voc/swimming.md`: 수영장 관련 VOC
    *   `data/voc/gym.md`: 체육관 관련 VOC
    *   `data/voc/program.md`: 프로그램/강습 관련 VOC
    *   `data/voc/other.md`: 기타 문의 관련 VOC
*   **백업**: 기존 HTML 파일은 `_unclassified/archive/voc/`로 이동.

### 2.2 UI/UX 및 기능 고도화
*   **통합 뷰어 구현**: `index.html`에서 VOC 메뉴 선택 시, `loadContent`를 통해 MD 파일을 로드하고 '아코디언' 스타일로 렌더링.
*   **개인정보 마스킹**: MD 데이터 파싱 시 또는 렌더링 시 작성자 이름을 자동으로 마스킹 처리하는 로직 적용.
*   **검색 연동**: `search_index.json`에 VOC 데이터 반영하여 전역 검색 지원.
*   **메뉴 일관성**: 사이드바와 메인 대시보드의 메뉴 구성을 1:1 매칭하여 사용자 혼선 방지.

### 2.3 보안 및 접근성
*   **입력 검증**: (향후 글쓰기 기능 고도화 시) XSS 방지를 위한 DOMPurify 적용 유지.
*   **웹 접근성**: 아코디언 요소에 `aria-expanded`, `aria-controls` 적용.

## 3. 상세 작업 단계

### 1단계: 디렉토리 정비 및 인덱스 생성
*   [NEW] `data/voc/` 폴더 생성
*   [NEW] `data/voc/0. voc_index.md` 생성 (폴더 관리 지침 준수)

### 2단계: 데이터 변환 (JS -> MD)
*   `pages/voc/voc_data.js`의 데이터를 추출하여 카테고리별 `.md` 파일로 변환 저장.
*   형식:
    ```markdown
    ## [접수완료/답변완료] 제목
    *   **작성자**: 홍*동 | **작성일**: 2025-02-13
    *   **문의내용**: ...
    *   **답변**: ...
    ```

### 3단계: 시스템 연동 (UI/UX 구현)
*   **index.html 수정**:
    *   **Sidebar**: '매뉴얼(시설)', '현황(History)', 'VOC(시민의 소리)' 아코디언 메뉴군 재배치.
    *   **Main Dashboard**: 3개 모듈(매뉴얼, 현황, VOC) 카드 UI 레이아웃 구현.
*   **search_index.json**: VOC 내용 포함하여 업데이트.

## 4. 검증 계획
*   **UI 테스트**: 모바일 및 데스크탑 해상도에서 VOC 아코디언 동작 확인.
*   **보안 테스트**: 작성자 이름이 정상적으로 마스킹(`홍*동`)되어 노출되는지 확인.
*   **검색 테스트**: VOC 제목이나 내용 키워드로 검색 시 해당 문서가 로드되는지 확인.

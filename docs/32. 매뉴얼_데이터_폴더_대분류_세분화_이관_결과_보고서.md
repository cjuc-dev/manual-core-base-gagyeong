## 1. 개요 및 배경

### 1.1 개요
본 보고서는 2026년 5월 18일 수립된 `31. 매뉴얼_데이터_폴더_대분류_세분화_이관_계획서`를 근거로, 사이드바 대분류 명칭을 **'분야'** 체계로 정식 개편하고 우측 본문에 **'가경국민체육센터'의 마스터 인덱스 마크다운(`.md`) 뼈대를 연동**하는 공용 라우팅 엔진 선행 구축을 성공리에 집행한 결과를 보고합니다.

> [!NOTE]
> **범위 축소 및 뼈대 선안착**
> 사용자 피드백에 따라 대규모 HTML to MD 변환은 향후 장기 과제(v5.60 이후)로 전격 이월하였으며, 본 차수에서는 **사이드바 명칭 개정, 상단 경로 네비게이션 연동 및 가경체육센터 마스터 인덱스(`.md`) 연동 뼈대 수립**을 선행 완수하여 실 구동 및 시각 무결성을 확보하였습니다.

### 1.2 주요 기대 효과
*   **분류 일관성 획득**: 레거시 '매뉴얼' 명칭을 **'행정 분야'** 및 **'기술 분야'**로 전격 승격하여, 직관적이고 세련된 대분류 메뉴 체계를 완성함.
*   **다단계 경로(Breadcrumb) 완벽 연동**: 상단 서브헤더 경로가 사용자의 요청에 따라 **`홈 / 행정 분야 / 가경국민체육센터`** 및 **`홈 / 기술 분야 / 가경국민체육센터`** 로 깨짐 없이 표시되게끔 라우팅 로직을 최적화함.
*   **데이터 자산 정합성 보장**: 가경국민체육센터의 이관된 마크다운 마스터 인덱스 파일들을 비동기(`fetch`) 기법으로 안전하게 로드하고, 미려한 marked.js 렌더링을 구현함.

## 3. 라우터 경로 매핑 및 렌더링 스니펫

### 3.1 신규 대분류 세분화 물리 경로 매퍼
`index.html` 내의 `loadContent` 함수 작동 시 `safeId`가 `admin_fields` 또는 `tech_fields` 일 때 가경국민체육센터의 물리 인덱스 파일(`.md`)을 동적으로 렌더링하도록 아래와 같이 라우터를 보강하였습니다.

```javascript
// 🚀 [v5.50] 대분류 세분화 물리 경로 매퍼 주입
} else if (safeId === 'admin_fields') {
    const folderMap = { '가경국민체육센터': 'gagyeong' };
    const folder = folderMap[facility] || 'gagyeong';
    fetchPath = `data/manual/admin/${folder}/0. ${facility}_행정분야_인덱스.md`;
} else if (safeId === 'tech_fields') {
    const folderMap = { '가경국민체육센터': 'gagyeong' };
    const folder = folderMap[facility] || 'gagyeong';
    fetchPath = `data/manual/tech/${folder}/0. ${facility}_기술분야_인덱스.md`;
}
```

*   **검증 결과 및 증적**:

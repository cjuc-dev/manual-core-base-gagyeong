# 📋 26. 시스템 문의 및 요청 게시판 구축 계획서

본 문서는 SOS 시스템 이용자가 겪는 불편사항이나 개선 요청을 직접 수렴하고, 관리자가 이에 대한 조치 결과를 투명하게 답변할 수 있는 '시스템 문의 게시판'을 구축하기 위한 공식 계획서입니다.

## 1. 목적
*   **시스템 개선 환류 체계 구축**: 사용자의 직접적인 피드백을 시스템 고도화의 근거로 활용.
*   **스크린샷 UI 완벽 구현**: 보내주신 다크 네이비 테마의 카드형 UI와 상태 배지 시스템 도입.
*   **독립적 데이터 관리**: 일반 시설 VOC와 분리하여 시스템 전체의 운영 이슈를 별도로 관리.

## 2. 주요 변경 사항

### 2.1 데이터 아키텍처 (Data Architecture)
*   **파일 신설**: `data/system/system_inquiry.md`
    *   **형식 표준화**:
        ```markdown
        ### [처리중] [시스템] 리뉴얼 요청합니다.
        *   **작성자**: 박*규 | **작성일**: 2025-11-28
        *   **내용**: 메인 대시보드 리뉴얼을 요청합니다.
        > **관리자 답변**
        > 현재 리뉴얼 작업이 진행 중입니다. 조속히 완료하겠습니다.
        ```

### 2.2 UI/UX 디자인 (UI Design)
*   **게시판 전용 스타일 클래스**:
    *   `.inquiry-card`: 그림자 및 둥근 모서리가 적용된 카드 레이아웃.
    *   `.badge-processing`: 처리중 (주황색 배경)
    *   `.badge-complete`: 완료 (초록색 배경)
    *   `.admin-reply-box`: 스크린샷과 동일한 다크 네이비 배경의 답변 영역.
*   **독립적 진입점 구축**:
    *   **사이드바**: '운영 현황' 하위가 아닌 별도의 **[시스템 문의/요청]** 최상위 버튼 배치.
    *   **대시보드**: 기존 3대 모듈(매뉴얼, 현황, VOC)에 더해 **4번째 독립 모듈 카드** 신설.

### 2.3 시스템 연동 (Integration)
*   **검색 엔진**: `search_index.json`에 문의 내용을 색인하여 전역 검색 지원.

## 3. 상세 작업 단계

### 1단계: 디렉토리 정비 및 파일 생성
*   [NEW] `data/system/system_inquiry.md` 생성.
*   [NEW] `data/system/0. system_index.md` 작성.

### 2단계: UI 스타일 및 게시판 레이아웃 구현
*   `index.html` 내 전용 CSS 스타일(스크린샷 기반) 추가.
*   메인 화면 및 사이드바 내비게이션에 메뉴 노출.

### 3단계: 지능형 렌더링 로직 적용
*   `loadContent` 함수에서 특정 파일(`system_inquiry`) 로드 시 카드형 UI로 자동 변환하는 파서 보완.

## 4. 검증 계획
*   **UI 재현도**: 배지 컬러 및 답변 박스 디자인이 스크린샷과 1:1 일치하는지 확인.
*   **다크모드 대응**: 테마 전환 시 답변 영역의 시인성 확보 여부 점검.
*   **검색 연동**: '리뉴얼' 등 키워드 검색 시 해당 문의가 즉시 검색되는지 확인.

# 🔄 글로벌 서브헤더 및 다단계 경로 내비게이션 구축 계획서

본 계획서는 청주도시공사 'Smart Operations Suite (SOS)' 통합 매뉴얼의 사용자 경험(UX)과 가독성을 극대화하기 위해, 상단 고정 헤더(COMMAND CENTER) 바로 아래에 상시 노출되는 **'글로벌 서브헤더 내비게이션 바(Global Sub-Header Bar)'**를 설계하고 안전하게 이식하기 위한 계획서입니다.

---

## 1. 추진 배경 및 목적
*   **현재 구조의 한계**:
    *   상세 지침서(예: 청주수영장 안내) 본문 내용이 길어 아래로 스크롤 시, 최상단에 위치한 **홈/경로 표시(Breadcrumb)** 및 **닫기 버튼**이 화면 밖으로 올라가 사라지는 문제 발생.
    *   스크롤이 내려간 상태에서 사용자가 "내가 현재 어느 시설의 지침을 읽고 있는지" 파악하기 어려워 인지적 부하 유발.
    *   문서를 닫기 위해 다시 맨 위로 스크롤을 올려야 하는 비효율성 잔존.
*   **구축 목적**:
    *   **글로벌 서브헤더 배치**: 메인 스크롤 영역(`mainScrollArea`) 외부인 `header` 하단에 상시 고정 영역으로 배치하여 스크롤에 영향받지 않는 독립성 확보.
    *   **홈 상시 노출 및 다단계 경로화**: 대시보드 상태에서는 '홈'만을 노출하고, 상세 페이지로 이동할 때마다 `홈 / 대분류 / 중분류 / 소분류` 형식의 디렉터리 경로를 지능적으로 렌더링.
    *   **통합 제어 단일화**: 닫기 버튼을 서브헤더로 끌어올려 중복 디자인을 해소하고 직관적인 복귀 채널 제공.

## 2. 상세 시스템 설계

### 2.1 UI/UX 레이아웃 구조 개편
*   **서브헤더 위치**: 우측 메인 영역의 `<header>` 바로 밑, `<main id="mainScrollArea">` 바로 위에 물리적으로 격리 배치.
*   **기본 디자인 톤앤매너**:
    *   **배경색**: `bg-gray-50/90 dark:bg-gray-900/90` (테마 맞춤 및 반투명)
    *   **블러 처리**: `backdrop-blur-md` 적용으로 본문 스크롤 시 고급스러운 투영 효과 선사.
    *   **경계선**: `border-b border-gray-200/60 dark:border-gray-800`를 주어 구획 분할 강화.
*   **중복 제거**: `#contentView` 최상단의 기존 닫기 버튼 영역(`div.flex.justify-end.mb-4`) 및 기존 `#mainScrollArea` 내부의 `#breadcrumbNav` 제거.

### 2.2 지능형 다단계 경로 빌더 (Breadcrumb Path Builder)
*   **대분류 판별**:
    *   `isVoc === true`: `시민의 소리 (VOC)`
    *   `guide` 계열 ID: `시설 안내`
    *   `manual`/`safety` 계열 ID: `시설 매뉴얼`
    *   `update` ID: `운영 현황`
    *   `system_inquiry` ID: `시스템 문의`
*   **중분류 판별**: `titleMap` 조회를 통한 한글 문서 제목(예: `청주수영장 안내`, `수영장 VOC`) 추출.
*   **소분류 판별**: 탭 선택 시 활성화된 시설 상세명(예: `영운국민체육센터`) 결합.
*   **결과 예시**:
    *   `홈 / 시민의 소리 (VOC) / 수영장 VOC`
    *   `홈 / 시설 매뉴얼 / 행정 매뉴얼 / 복대국민체육센터`

## 3. 지침 준수 및 안정성 계획

### 3.1 변경관리 지침 준수
*   **물리 백업 선제적 확보**: 작업 실행 직전 `versions/index_v5.44_pre_v5.45_backup.html` 백업본 생성.
*   **SPA 라우팅 및 상태 유지**: `popstate` 발생 시 서브헤더 정보가 자동으로 동기화되도록 `showDashboard()` 및 `loadContent()` 내부에서 경로를 강제로 갱신/초기화.
*   **스타일 분리**: 불필요한 인라인 스타일 배제, Tailwind CSS 표준 클래스만을 사용하여 정렬 유지.
*   **웹 접근성**: 닫기 버튼에 `aria-label="문서 닫기"` 및 active 모션 효과 부여.

### 3.2 3대 통합 마스터 문서 최신화
*   동시 반영 예정 핵심 문서:
    1.  `README.md` 내 버전 업데이트 이력 추가.
    2.  `docs/체육시설 통합 매뉴얼 시스템 설명서.md` 업데이트 이력 및 시스템 아키텍처 항목 최신화.

## 4. 검증 계획

### 4.1 수동/자동 통합 브라우저 검증 시나리오
1.  **초기 화면 진입 검증**:
    *   검색창 하단에 `홈` 텍스트와 집 모양 에메랄드 아이콘이 정상 고정되어 노출되는가?
    *   대시보드 상태에서는 우측 `닫기` 버튼이 완벽히 가려져 (`hidden`) 있는가?
2.  **문서 클릭 시 경로 확장 검증**:
    *   '시민의 소리 -> 수영장' 클릭 시 `홈 / 시민의 소리 (VOC) / 수영장 VOC` 경로가 부드럽게 렌더링되는가?
    *   상세 문서가 열렸을 때 우측 상단에 장미색 X 마크가 있는 `닫기` 버튼이 즉각 노출되는가?
3.  **스크롤 및 고정성(Sticky/Fixed) 검증**:
    *   본문 영역을 깊게 스크롤해 내릴 때, 글로벌 서브헤더 바가 흔들림 없이 최상단에 상시 정착되어 있는가?
    *   본문 내용이 흐르며 서브헤더 밑으로 지나갈 때 반투명 블러 처리가 고풍스럽게 흐려져 보이는가?
4.  **복귀(닫기) 및 PopState 검증**:
    *   우측 상단의 `닫기` 버튼 클릭 시 메인 대시보드로 무사히 복귀하고 경로 정보가 깔끔하게 `홈`만 남고 리셋되는가?
    *   브라우저 뒤로가기를 눌렀을 때도 오작동 없이 상태가 백업 복구되는가?

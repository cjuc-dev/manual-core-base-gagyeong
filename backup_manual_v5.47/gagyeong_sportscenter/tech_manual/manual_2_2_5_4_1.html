주요구성

  • 염소 자동 측정장치
    [1]

    염소 자동 측정장치는 수영장, 정수장, 공공 수처리 시설 등에서 물속의 잔류 염소 농도를 자동으로 측정하는 장비입니다.

    실시간으로 염소 농도를 감지하여, 수질을 일정하게 유지하고 적정한 살균 효과를 보장하는 역할을 합니다.

    1. 염소 자동 측정장치의 주요 기능
    • 물속의 자유 염소(Free Chlorine), 결합 염소(Combined Chlorine), 총 염소(Total Chlorine) 농도를 자동 감지
    • ppm 단위로 수치를 표시하여 정확한 데이터 제공
    • 시설의 염소 자동 측정장치는 자유 염소만 측정이 가능하다.

    2. 🏊‍♂️ 수영장 → 법적 기준(자유 염소 0.4~1.0 ppm) 유지

    3. 차염 주입펌프와 연동하여 자동으로 수질 조절 가능

    4. 수영장, 정수장, 공공시설에서 필수적으로 사용됨

  • pH 자동 측정장치
    [1]

    pH 자동 측정장치는 수영장 시설에서 물의 pH 값을 실시간으로 측정하는 장비입니다.

    pH 값이 설정된 범위를 벗어나면 자동으로 pH 주입펌프와 연동하여 pH조절제를 주입하여 수질을 일정하게 유지하는 역할을 합니다.

    1. pH 자동 측정장치의 주요 기능
    • 물속의 pH 값을 실시간으로 감지하고 디지털 디스플레이를 통해 수치를 표시
    • 일반적인 🏊‍♂️ 수영장 → 적정 pH 범위는 7.2~7.6 유지
    • pH 주입펌프와 연결하여 산성 또는 알칼리성 용액을 자동 주입하여 pH 값 조절

    2. 법적 기준(pH 5.8~8.6)

    3. 수영장, 정수장, 공공시설에서 필수적으로 사용됨

  • 차염 주입펌프
    [1]
    차염 주입펌프의 주요 기능

    소독제(차염) 자동 주입

    • 수영장 물에 차염(소독제)을 설정된 농도로 자동 투입
    • 잔류 염소 농도를 일정하게 유지 (법적 기준: 0.4~1ppm)
    • 염소 자동 측정장치와 연동하여 필요할 때만 주입 가능 → 염소 과다 주입 방지

    수질 자동 조절 기능

    • pH 자동 측정장치 및 차염 측정 장치와 연동 가능
    • 염소 농도가 낮아지면 자동으로 차염을 추가 주입
    • 염소 농도가 높아지면 차염 주입을 중단하여 과다 투입 방지

  • pH 주입펌프
    [1]

    pH 주입펌프는 수영장 물의 pH를 일정하게 유지하는 장치입니다.

    pH 주입펌프의 주요 역할
    • pH 조절: 알칼리성일 경우 산성 물질 주입, 반대의 경우 알칼리성 물질 주입
    • 소독제 효율 최적화: 적정 pH 유지로 살균 효과 극대화
    • 사용자 안전 보장: 피부 자극 최소화
매뉴얼

  • 1️⃣ 유리잔류염소 보정법📋

  • 초기 화면에서 를 3회 눌러 Calibration 으로 진입후 를 2회 눌러 DPD-value 화면으로 진입한다.

    • Calibration 화면
    DPD-value 화면

  • 숫자가 깜빡이면 를 1회 누르고 버튼을 눌러 자릿수를 이동한다.

    와 를 눌러 측정한 염소 값으로 숫자를 변경한다.

    예) 현재 수질의 염소 농도가 0.8ppm이라면 0.8로 입력한다.

    • DPD-value 보정

  • 보정값 입력이 완료되었다면 를 2회 누르고 를 3회 눌러 초기화면으로 나간다.

    • Calibration 보정 종료

  • 2️⃣ 약품 농도 셋팅 설정법📋

  • 초기 화면에서 를 7회 눌러 Control setting로 진입 후 를 3회 누른다.

    • Control setting 화면
    set point 화면

  • 숫자가 깜빡이면 를 1회 누르고 를 눌러 자릿수를 이동하며, 와 를 눌러 원하는 염소 농도 값으로 숫자를 변경한다.

    예) 염소 투임 농도를 2.00ppm으로 원한다면 2.00으로 입력한다.

    • set point 변경 전
    set point 변경 후

  • 를 3회 누르고 를 2회 누른다.

    를 1회 눌러 변경된 설정값을 확인한다.

    • set point 변경 확인

  • 3️⃣ 유리잔류염소 센서 설치 방법📋

  • 유리잔류염소 센서와 멤브레인 캡을 분리하고 전해액 끝부분을 잘라낸 후 멤브레인 캡 안에 주입한다.

    ⚠️ 공기방울이 생기지 않게 주입한다.

    • 유리잔류염소와 전해액
    맴브레인 캡 전해액 주입

  • 전해액이 담긴 멤브레인 캡을 센서 본체와 체결한다.

    ⚠️ 일부 전해액과 함께 일부 공기방울이 빠져나오는 것을 확인한다.

  • 고무패킹과 플라스틱링을 그림의 순서와 같이 결합한다.

    • 센서와 맴브레인 캡 체결
    센서 결합

  • 결합한 염소센서를 하우징 안에 체결한다.

  • 드라이버로 센서 케이블을 결선한다.

    ⚠️ 갈색선: 1번 / 희색선: 2번

    • 센서 하우징 체결
    센서 케이블 결선

  • 케이블 결선 후 윗 커버를 체결한다.

  • 하우징 밸브를 열어 물이 흐르는 것을 확인한다.

    • 커버 체결
    물의 이동 확인

  • 4️⃣ Ph센서 보정법📋

  • ph센서와 퍼버용액을 준비한다.

    [ 초록색: 퍼버7 / 빨간색: 퍼버4 ]

  • ph센서를 꺼내 케이블과 결선한다.

    • 센서와 퍼버용액
    센서와 케이블 체결

  • 휴지로 ph센서를 깨끗이 닦아준다.

    [너무 세게 문지르지 말고 물기만 없애 준다.]

  • ph센서를 퍼버7 용액에 넣고 약 30초 동안 기다린다.

    • 센서 이물질 제거
    퍼버7용액 측정 준비

  • CAL 을 2회 누룬후 화면 7.00 ph 수치가 표기됨을 확인한 후 CAL 을 1회 누른다.

    • 표기 상태 확인
    측정 시작

  • 측정이 끝날 때까지 기다리고 완료되면 CAL 을 1회 누른다.

  • ph센서를 퍼버7 용액에서 빼낸 후 휴지로 부드럽게 닦아준다.

    • 측정 후 확인
    센서 물기 제거

  • ph센서를 퍼버 4용액에 넣고 약 30초 동안 기다린다.

  • 화면에 4.00 ph 수치가 표기됨을 확인한 후 CAL 을 1회 누른다.

    • 퍼버4 측정 준비
    측정 시작

  • 측정이 끝날 때까지 기다리고 완료되면 CAL 을 1회 누른다.

  • 초기화면으로 돌아감을 확인 후 완료한다.

    • 측정 후 확인
    ph 보정 완료

  • 5️⃣ ph 셋팅포인트 설정법📋

  • MENU 버튼을 1회 누른 후 아래 화살표 버튼을 이용해 CONTROL 로 이동한 후 OK 버튼을 누른다.

    • 초기화면
    CONTROL 선택

  • 아래 화살표 버튼을 눌러 SET 으로 이동한 뒤 OK 버튼을 누른다.

  • 오른쪽 화살표 버튼으로 자리이동을 하고 상하 버튼을 눌러 원하는 셋팅 포인트로 설정한 뒤 OK 버튼을 누른다.

    • SET 선택
    세팅값 설정

  • ESC 버튼을 2회 눌러 초기화면으로 전환한 뒤 우측 상단에 세팅된 설정값을 확인한다.

    • 초기화면 세팅 적용 확인

  • 8️⃣ 염소 측정기 PH에서 CL 변경법📋

  • 초기 화면에서 1번째 버튼을 10회 눌러 General Setting 화면을 띄운다.

    • General Setting 화면

  • General Setting 화면에서 3번째 버튼을 3회 눌러 측정기 선택 창을 띄운다.

  • 윗방향키나 아래방향키를 눌러 염소 측정으로 변경한다.

    • 염소 측정 선택

  • 5번째 버튼을 2번 눌러 초기 화면에서 측정 방법이 변경되었는지 확인한다.

    • 변경된 측정 방법 확인

  • 염소 수치 하한선과 상한선을 0.00 ~ 10.00으로 변경한다.
    [숫자 변경 방법은 기존 방식과 동일]

    • 염소 수치 설정

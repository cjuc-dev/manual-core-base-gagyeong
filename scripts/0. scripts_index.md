# 🛠️ Scripts 폴더 안내 (Maintenance Tools)

본 폴더는 시스템 데이터 갱신, 백업, 정리 등을 자동화하기 위한 도구들을 포함하고 있습니다.

---

### 📂 주요 파일 구성

1.  **[build_search_index.js](build_search_index.js)**:
    *   **역할**: `data/facilities/`의 모든 마크다운 파일을 분석하여 검색 색인을 생성합니다.
    *   **실행**: `node scripts/build_search_index.js` (파일 추가/삭제 후 필수 실행)
2.  **[cleanup_garbled.js](cleanup_garbled.js)**:
    *   **역할**: 파일 시스템 내의 손상된 파일명이나 임시 파일을 정리합니다.
3.  **[test/](test/)**:
    *   **역할**: 신규 기능 도입 전 실험적인 코드나 테스트를 진행하는 안전 공간입니다.

(2) 관련 법령

  • 수도법 제33조 ( 수돗물의 공급시설의 관리 ) 수돗물을 공급받는 자는 저수조를 위생적으로 관리해야 할 책임이 있음.
  • 수도법 시행령 제55조 ( 저수조의 청소 및 위생관리 등 ) 저수조의 내부는 1년에 1회 이상 정기적으로 청소해야 하며, 다중이용시설 또는 대형 저수조의 경우 6개월에 1회 이상 청소가 권장됨.
  • 공중위생관리법 시행규칙 제4조 공중이용시설(목욕탕, 수영장 등) 의 경우, 급수설비 및 저수조는 정기적으로 세척·소독해야 하며, 그 결과를 기록해야 함.

2. 저수조 청소 매뉴얼

  • 생활용수 저수조 탱크 (56톤/2실) , 밸런스 탱크 (36톤/1실) 로 구성되어 있다.
    생활용수 탱크
    밸런스 탱크
  • 생활용수 저수조 탱크는 2개의 실 로 나뉘어져 있으며 A실, B실 로 구분하여 설명한다.
  • ❗ 탱크 청소 순서 는 생활용수 탱크 A실 ➡️ 밸런스 탱크 ➡️ 생활용수 탱크 B실 순서로 진행한다.
  • 생활용수 탱크 청소 전 탱크 내부의 물을 배출(배수, 드레인)하여 탱크의 수위를 낮추는 작업을 진행한다.
  • ❗ 작업 전 생활용수 탱크의 수위 레벨 컨트롤러의 LOW 값과 START 값을 ⚙️ 조정한다.
    ⚙️ 솔레노이드 관련 설정 안내
    • 💡 LOW 5%, START 0.5%로 변경 적용하여 저수위로 인한 상수도 자동 보충을 1차적으로 방지.
    • 💡 솔레노이드 밸브 제어 신호가 지속 ON 상태일 경우 과열·고장 원인이 될 수 있음.
      • HIGH
      LOW
      START
      STOP
      • HIGH : 탱크 레벨 고수위 경보
      • LOW : 탱크 레벨 저수위 경보
      • START : 저수조 상수도 보충 솔레노이드 밸브 OPEN 시점
      • STOP : 저수조 상수도 보충 솔레노이드 밸브 CLOSE 시점
  • ❗ A실 상부 상수도 공급 밸브 를 잠가 2차적 상수도 공급 을 차단한다.
    상수도 공급 차단
  • ❗ 탱크 드레인 배수 작업 전 밸런스 탱크로 생활용수를 공급 하여 밸런스 탱크를 보충한다.(수영장 컨트롤 판넬 시수밸브 활성화)
    밸런스 탱크 보충
  • ⚠️ 위와 동시에 수영장 여과기 역세 작업 을 진행하여 탱크 수위를 낮춘다.
    여과기 역세
  • ✅ 지하 배수피트가 1개소로 대량 드레인이 곤란하므로, 생활용수 탱크의 물을 밸런스 탱크 공급 + 역세 로 수위를 낮추는 방식이 더 효과적임(배수작업 대체).
  • ❗ 생활용수 탱크(A, B실) 수위가 약 20~30% 도달 시 밸런스 탱크 공급 중단 .
    탱크 수위 확인
  • 🚨 저수위로 인한 탱크 토출측 배관(부스터 펌프 연결) 공기 유입 에 주의.
  • ❗ 생활용수 탱크 A실 → 부스터 펌프 연결 밸브 차단 ⚠️ B실 밸브는 개방 상태를 유지하여 부스터 펌프의 청소용 공급수 로 활용.
    A실 밸브 차단
  • 💡 캐비테이션(cavitation) 은 펌프 내부에서 발생하는 기포 파괴 현상으로 펌프 손상 및 작동 불안정의 원인이 될 수 있음.
  • 캐비테이션 예방 → 부스터 펌프 보호 및 고장 저감
  • 단일 배수피트 환경에서 안전·효율적인 수위 저감 절차 확립
  • ⚠️ A실의 남은 물은 드레인 밸브 를 개방하여 자연 배수 시키며, 배수피트 배수 처리 상태 를 확인하면서 배수 작업을 진행한다.
    생활용수 배수
    생활용수 탱크 드레인 밸브
    배수 피트 상태 확인
  • A실의 배수 상태에 따라 내부 청소 를 실시하고, A실 청소 작업 동안 다음 단계(밸런스 탱크 ) 준비를 위해 밸런스 탱크 배수 작업 을 병행한다.
    밸런스 탱크
    • 밸런스 탱크 수위를 낮추기 위해 역세를 최대한 실시하여 수위를 조정한다.
    • 🚨 탱크 수위가 LL(저수위) 지점에 도달하면 수영장 순환펌프는 자동 정지된다.
    • 밸런스 탱크의 LL 수위를 약 20% 수준으로 설정하여, 탱크 토출측 수위에 가깝게 유지한다.
    • ⚠️ 탱크의 잔여 수위는 드레인 밸브 를 개방하여 자연 배수 시키며, 배수피트 배수 처리 상태 를 확인하면서 배수 작업을 진행한다.
      • 역세 작업
      탱크 수위 확인
      밸런스 탱크 드레인 밸브
      배수 피트 상태 확인
  • 🚨 밸런스 탱크 배수 진행 중에는 탱크 보충(상수도) 을 정지 한다.
  • 🚨 컨트롤 패널을 ⚙️ 자동 → 수동 으로 전환하고, 수질 자동측정장치 전단 유입 밸브 를 차단하여 약품 주입 을 정지한다.
    수처리 수동 전환
    수질자동측정장치 밸브 조작
  • 🚨 밸런스 탱크 청소 작업 진행 동안에 수영장 순환펌프 전단의 집모기의 분해 청소 를 실시한다.
    • 수영장 순환펌프 집모기 청소(연 2회)
      • 순환펌프 A, B 펌프 전단 밸브를 잠근다.
      • 순환펌프 토출측 밸브 를 잠근다.
      • 집모기 하부 드레인 밸브 를 열어 내부 물을 배출한다.
      • 집모기 덮개 고정 볼트 를 풀어 덮개를 개방하고 여과망의 이물질 제거·세척 을 실시한다.
      • 세척 완료 후 하부 드레인밸브를 잠그고 밸런스 탱크 토출측 밸브 를 서서히 열어 집모기에 물을 가득 채운다 .
      • 집모기 물이 가득 차면 밸런스 탱크 토출측 밸브를 잠그고 덮개 고정 볼트 체결 .
      • 밸런스 탱크 토출측 밸브를 열어 누수 여부 를 확인한다.
      • 집모기 에어밴트 를 충분히 하여 캐비테이션 방지 .
      집모기 세척
      에어밴트
    • 밸런스 탱크 토출측 밸브 위치 이상 으로 물이 보충되면 토출측 밸브를 개방한다.
      토출 밸브 개방
    • 순환펌프 가동 후 순환 상태 및 집모기 누수 여부 를 확인한다.
      순환·누수 점검
    • 자동운전 가동 조건 충족 시 설비를 자동운전 으로 전환하고, 수질 자동측정장치 밸브를 연다.
      자동운전 전환
    • 최종 점검 : 탱크 수위, 드레인 밸브 개폐, 자동 제어 복귀 여부를 확인한다.
      최종 점검
    • 1~4층 수전(화장실·샤워장·소/대변기) 에어밴트 작업 을 실시하며 저수조 청소 작업을 마친다.
      수전 에어밴트

## 📁 파일 구성 안내

### 1. [0. system_index.md](file:///d:/Smart%20Operations%20Suite/체육시설%20통합%20매뉴얼/data/system/0.%20system_index.md)

*   **지침**: 신규 시스템 파일 추가 시 반드시 본 인덱스를 최신화해야 합니다.

*   **지침**: 매뉴얼이나 문의 내용이 업데이트되면 이 파일을 동기화해야 검색이 가능합니다.

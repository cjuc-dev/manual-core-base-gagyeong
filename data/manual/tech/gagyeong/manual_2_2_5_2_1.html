가. AISS(자동고장구간개폐기) 3P 25.8kV 200A

AISS 패널 전면
AISS 조작부 기능 안내

핵심요약

  • 정의 : Air-Insulated Auto Sectionalizing Switch — 고장 시 해당 구간만 자동 분리 하는 장치(주로 22.9 kV 인입부).
  • 위치 : 한전 책임 분기점 인근 수용가측 AISS 패널 .
  • 운용 : 패널에서 차단기 투입·개방 및 송전 상태 확인 가능.

1) 개요

  • AISS 는 고장 발생 시 상위 장치의 차단·재폐동을 감지해 무전압 상태에서 개방 하여 고장 구간만 분리.
  • 패널 계기를 통해 송전/무전압 상태를 즉시 확인.

2) 역할·효과

  • 역할 : 상위 리클로저/차단기 와 보호협조 → 상위 차단 후 AISS 개방 → 사고 구간 격리 , 건전 구간 신속 재송전 .
  • 효과 : 정전 범위 최소화, 복구 시간 단축, 계통 안정성 향상. 🚀

3) 동작 원리(핵심)

  • AISS는 차단기가 아님 — 고장전류 직접 차단 X, 무부하 개방 으로 구간 분리.
  • 상위 장치의 차단/재폐동 을 감지하여 동작.

4) 설치·적용 포인트

  • 수용가 변전실 인입부 적용. 부하 특성(일반/특수)과 보호철학에 맞게 선정.
  • 문서 내 이미지는 계통도 먼저 → 본문 → 단계별 사진 순서로 배치.

5) 운전(기본)

  • 투입 : 계통 이상 없음 확인 → 인터록·접지 해제 → 원격/현장 투입 .
  • 개방 : 계획개방(점검/작업) 또는 고장 시 자동개방 상태 확인 .
  • 확인 : 패널 전압·전류·상태등으로 송전/무전압 점검.

6) 안전 유의사항

  • 개폐 전 무전압·무부하 확인 및 접지 확인 필수.
  • 리클로저 재폐 횟수/설정 임의 변경 금지, 변경 시 기록 유지.
  • LOTO (잠금/표지) 준수, 감전·아크플래시 PPE 착용.

나. 고압용 전자식 전력량계(DM, VAR)

AISS 컨트롤러 전면
전자식 전력량계 항목(예시)

핵심요약

  • 정의 : CT·PT 2차 신호를 디지털로 샘플링해 kWh (유효전력량), kW(DM) (최대수요전력), kvarh(VAR) (무효전력량) 등을 계측·집계하는 고압용 전자식 계량기.
  • 위치 : 수전 인입부 계량함 또는 수배전반 계량 패널(CT·PT 2차 근접).
  • 운용 : 검침·요금정산, 수요전력 관리, 역률(PF) 개선 상태 확인, 원격 통신(예: RS-485/Modbus) 지원.

1) 개요

  • 계량 항목: 전력량( kWh ), 무효전력량( kvarh ), 최대수요전력( kW DM ), 전압/전류, 주파수, 역률(PF) 등.
  • 표시·기록: LCD/LED 표시, 수요전력 수집 간격(예: 15분) , 일/월 누계, 이벤트·경보 로그.

2) 기능·효과

  • 요금 정산 근거 제공(kWh/DM/역률). 시간대별 사용량 분석 및 피크 억제에 활용.
  • 수요전력(DM) 관리 : 피크 예경보로 부하 제어·운전계획 최적화 → 계약전력 초과 방지.
  • 역률 개선 지표 제공(VAR, PF) → 콘덴서 운전 최적화로 벌과금 예방. 🚀

3) 동작 원리(핵심)

  • CT·PT 2차 전압/전류를 디지털 샘플링 → 순간 전력 계산 → 적산하여 kWh/kvarh 산출.
  • DM(최대수요전력) : 설정 주기(예: 15분) 평균 kW 중 월 최대값 기록(Reset 주기 설정 가능).

4) 설치·배선 포인트

  • CT/PM 변비 설정 (예: CT 400/5A, PT 22.9kV/110V)을 계량기 파라미터에 정확 반영.
  • 극성·상순서 준수(S1-K, S2-L 등) 및 2차 접지/퓨즈 확인, PT 2차 결선 오배선 방지.
  • 통신선(RS-485)은 전력선과 분리 포설, 종단저항·주소·통신속도 통일.

5) 운전(기본)

  • 초기 설정 : CT/PT 비, 수요간격(예: 15분), DM Reset 주기, 시간/캘린더 동기화.
  • 점검 : 계측치(kW, PF)와 설비 운전 상태(부하, 콘덴서) 비교로 이상 유무 확인.
  • 데이터 연계 : BEMS/원격검침과 연동(주소/프로토콜 일치) 및 월말 데이터 백업.

6) 안전 유의사항

  • CT 2차 개방 금지 (점검·탈거 전 단락 필수), PT 2차 퓨즈 ·절연 확인.
  • 결선·설정 변경 시 LOTO 준수, 감전·아크플래시 PPE 착용.
  • 검정·검침 규정 준수(봉인 훼손 금지), 파라미터 변경 이력 관리.

다. TR, COS (몰드 변압기)

몰드 변압기/COS 전면

핵심요약

  • 정의 : TR (몰드 변압기, Cast Resin)은 특고압을 저압으로 변환하는 변압기, COS (Cut-Out Switch)는 변압기 1차측 퓨즈 일체형 개폐기 (보호/개방).
  • 위치 : 한전 인입 → AISS/차단기 → COS(1차측) → 변압기(TR) → 저압배전반(2차측).
  • 운용 : 변압기 온도/팬 상태 확인, COS 퓨즈 상태 점검, 무부하 확인 후 개폐 절차 준수.

1) 개요

  • 몰드 변압기: 난연 수지로 권선을 주입 성형 해 절연·방습·내환경성을 높인 배전용 변압기.
  • COS : 변압기 1차측 과전류·단락 보호용 퓨즈 와 개폐 기능 을 겸한 장치.

2) 기능·효과

  • 안전·신뢰성 : COS 퓨즈가 변압기 1차측 보호, 몰드 구조로 난연·저유지보수 .
  • 운영 효율 : 변압기 온도 감시로 과부하/냉각 관리, 고장 시 구간 분리 용이. 🚀

3) 설치·운전 포인트

  • 결선·정격 : 1차/2차 결선(Y/Δ), 전압비·용량, %임피던스 확인. COS 퓨즈 정격 은 변압기 정격전류·투입전류 고려.
  • 접지 : 변압기 프레임/심선 접지, 2차측 중성점 접지 방식 확인.
  • 온도·냉각 : 온도센서(예: PT100)·팬 동작, 알람/트립 설정값 문서화.
  • 개폐 절차 : 저압차단기 개방 → 무부하 확인 → 1차측 COS 개방 (투입 시 역순).

4) 안전 유의사항

  • 무전압·무부하 확인, LOTO 준수, 감전·아크플래시 PPE 착용.
  • 여자 돌입전류·잔류자속 주의, COS 퓨즈 교체 시 정격·극성 확인.
  • 권선·단자부 이물/균열·과열 흔적 점검, 진동/소음 이상 시 운전 제한.

라. GIMAC, ACB, 콘덴서

GIMAC / ACB / 콘덴서

핵심요약

  • 정의 : GIMAC 은 각상 전압·전류·위상·역률 표시 및 콘덴서 자동투입 설정 이 가능한 통합 계측/제어 장치, ACB 는 변압기 후단 주차단기 , 콘덴서 는 역률 보상 설비.
  • 위치 : 변압기 2차측 ACB → 배전반 → GIMAC(표시/제어) 및 콘덴서 뱅크 .
  • 운용 : GIMAC에서 역률 목표·단 투입 설정, ACB로 계통 개폐, 필요 시 콘덴서 수동 투입/차단 .

1) 개요

  • GIMAC : 각상 V/I, PF, 위상 등을 실시간 표시, 역률 목표값 설정에 따라 콘덴서 자동 제어.
  • ACB : 변압기 후단 주차단기로, 한전 정전·계통 이상 시 우선 Trip . 작업 시 레버로 투입/개방 가능.
  • 콘덴서 : 설정 역률 미만 시 자동 투입되며, 필요 시 패널에서 수동 조작 가능.

2) 기능·효과

  • 역률개선 으로 무효전력(kvar) 저감, 과금/손실 최소화.
  • 계통보호/운전 : ACB로 안전한 분리·투입, GIMAC으로 상태 모니터링·자동 제어. 🚀

3) 설치·운전 포인트

  • GIMAC 설정 : 목표 역률, 단계별 투입용량/지연시간, 우선순위 설정.
  • ACB : 정격·보호정정(LSIG) 확인, 시험(Trip/Close) 및 메카니즘 점검.
  • 콘덴서 : 단계 용량·접촉기 정격, 방전저항·퓨즈 확인. 고조파 환경 시 필터형 검토.

4) 안전 유의사항

  • 무전압·무부하 상태 확인 후 ACB 개폐, LOTO 준수.
  • 콘덴서 잔류전하 완전 방전 후 작업(방전저항 확인).
  • GIMAC/콘덴서 설정 변경 시 변경이력 문서화, 과·부족보상 주의.

마. MCCB(배선용차단기)

MCCB 분기 차단기

핵심요약

  • 정의 : 변압기 2차측 ACB 이후, 각 층/주요 설비로 분기되는 회로에 설치된 배선용 차단기 (MCCB).
  • 용도 : 특정 층 또는 특정 설비만 개별 차단 가능(국부 정전 대응).
  • 운용 : 과부하·단락 보호 및 계획 정전/점검 시 회로 개별 개폐 .

1) 개요

  • MCCB는 프레임·정격 전류(예: 100/225AF 등)에 따라 분기회로를 보호/개폐하는 주 분기 차단기 입니다.
  • 한전 정전과 무관하게 특정 층만 정전 인 경우, 해당 회로 MCCB 상태 점검/조작으로 대응합니다.

2) 기능·효과

  • 보호 : 과부하/단락 시 자동 트립으로 배선·부하 보호.
  • 운전 편의 : 층·구역별 개별 차단 가능 → 국부 정전/작업 구간 분리 용이.

3) 설치·운전 포인트

  • 정격·정정 : 프레임/정격전류, 트립 정정(LSI 등)과 배선 용량 일치 확인.
  • 접속 : 단자 체결 토크, 버스바/케이블 발열·변색 여부 주기 점검.
  • 라벨링 : 층/구역·부하명 표기, 회로도와 일치 관리.

4) 안전 유의사항

  • 조작 전 무부하 확인 , 필요 시 상위 ACB로 구간 분리 후 작업. LOTO 및 PPE 필수.
  • 트립 원인(과부하/단락) 미확인 상태에서 임의 재투입 금지, 원인 분석 후 복구.

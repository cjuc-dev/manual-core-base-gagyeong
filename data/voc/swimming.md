# [수영장 및 이용 FAQ]

## [청주수영장] 강습 및 이용 규정
| 항목 | 내용 |
| :--- | :--- |
| **강습 신청** | 매월 21일~말일까지 현장 및 온라인 접수 |
| **어린이 강습** | 주중 어린이반 운영(보호자 동반 필수), 온라인 접수 불가(방문만 가능) |
| **주말 운영** | 주말은 강습 없이 자유수영으로만 운영 |
| **연기 규정** | 잔여일 15일 이상 시 1회 한정(1개월 자동 연기, 재이월/환불 불가) |
| **환불 규정** | 당일 100%, 개시 전 10% 공제, 개시 후 위약금 10%+이용일수 차감 |
| **개인 강습** | 1:1 개인강습 없음, 단체 강습만 진행 |
| **오리발 이용** | 토요일 오전에만 전용 레인에서 사용 가능 |

## [청주수영장] 시설 및 서비스 안내
| 항목 | 내용 |
| :--- | :--- |
| **주차 안내** | 예술의전당, 인라인경기장 등 이용 가능(최대 3시간 무료주차) |
| **헬스장 이용** | 수영장 고객용 체력단련실 운영(2시간 이내, 실내전용운동화 지참) |
| **시설 규격** | 50m 레인 10개 보유(수심 2m 5개, 1.2~1.4m 5개) |
| **수온/환경** | 28~29℃ 적정온도 유지, 체온유지실 운영 |
| **사물함** | 월 강습회원 대상(월 2,000원), 매월 21일~말일 신청 |
| **기타 서비스** | 휴대폰 충전기 제공, 도서 대여(회원증 필요), 셔틀버스 미운행 |

## [가경국민체육센터] 시설 이용 FAQ
| 항목 | 내용 |
| :--- | :--- |
| **헬스장** | 헬스장 없음 (수영장, 체육관, 프로그램실만 운영) |
| **매점 위치** | 가경국민체육센터 3층에 위치 |
| **복장 제한** | 비규격(면, 청바지 등) 입장 불가, 인가된 수영복(래쉬가드 포함)만 가능 |
| **준비물** | 수영복, 수모, 수경, 수건, 개인 샤워도구 지참 |

## [복대국민체육센터] 시설 이용 FAQ
| 항목 | 내용 |
| :--- | :--- |
| **헬스장** | 헬스장 없음 (수영장, 체육관, 프로그램실만 운영) |
| **개인사물함** | 개인 사물함 없음(키오스크 배정 번호 락커만 이용 가능) |
| **주차 혜택** | 자유수영/강습 3시간, 체육관 대관 5시간 무료 (등록 필수) |
| **강습 혜택** | 수영강습생은 강습 없는 날 일일 1회(2시간) 자유수영 가능 |
| **수영용품** | 센터 내 수영용품 매장 미운영 |
